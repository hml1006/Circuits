# 20.2 离散时间信号与系统

> **前置知识**：[3.6 正弦稳态分析](../电路原理/3.6-正弦稳态分析.md)（LTI 系统的卷积与时域响应的连续对应）、[20.1 从连续到离散](20.1-从连续到离散.md)、[5.6 时序逻辑电路](../数字电路/5.6-时序逻辑电路.md)。本章建立离散时间信号与系统的术语与运算工具，是后续 Z 变换与滤波器的分析基础。

## 1. 序列与基本离散信号

### 1.1 序列表示与基本运算

离散时间信号用下标序列表示：

$$
x = \{ x[n] \}, \quad n \in \mathbb{Z}
$$

其中 $n$ 是整数序号，$x[n]$ 是第 $n$ 个采样值。与连续信号不同，$n$ 只能取整数。序列的基本运算包括：

- **移位**：$x[n-k]$ 整体右移 $k$ 个样本（延迟）
- **折叠**：$x[-n]$ 关于纵轴翻转
- **加减与数乘**：$x_1[n] + x_2[n]$、$a\, x[n]$
- **累加**：$\sum_{k=-\infty}^{n} x[k]$
- **差分**：$\nabla x[n] = x[n] - x[n-1]$

这些运算是后续建立卷积、差分方程等工具的基础。

### 1.2 基本序列：单位脉冲与单位阶跃

**单位脉冲（单位采样）序列**定义为

$$
\delta[n] = \begin{cases}
1, & n = 0 \\
0, & n \ne 0
\end{cases}
$$

离散 $\delta[n]$ 与连续冲激 $\delta(t)$ 不同：它取值有限（这里是 1），可以逐点运算，是离散系统分析中最基本的"探针"。

任何序列都可以表示为移位单位脉冲的加权叠加：

$$
x[n] = \sum_{k=-\infty}^{\infty} x[k]\, \delta[n-k]
$$

这一式子是卷积与系统分析的出发点。

**单位阶跃序列**定义为

$$
u[n] = \begin{cases}
1, & n \ge 0 \\
0, & n < 0
\end{cases}
$$

它与单位脉冲互为差分/累加关系：

$$
\delta[n] = u[n] - u[n-1], \qquad u[n] = \sum_{k=-\infty}^{n} \delta[k]
$$

### 1.3 指数序列、正余弦序列与周期性

实指数序列与复指数序列：

$$
x[n] = a^n u[n], \qquad x[n] = e^{j\omega n} = \cos(\omega n) + j\sin(\omega n)
$$

其中 $a$ 为实数时 $|a| < 1$ 对应衰减序列、$|a| > 1$ 对应增长序列。

正余弦序列 $x[n] = \cos(\omega_0 n + \varphi)$ 的周期性有特殊要求：只有当

$$
\omega_0 = \frac{2\pi m}{N}, \quad m, N \text{ 为整数}
$$

时，序列才以周期 $N$ 重复。这意味着并非所有 $\omega_0$ 都对应严格的周期序列，且离散正弦与连续正弦在周期性上存在本质差异。

## 2. 线性时不变（LTI）系统

### 2.1 线性、时不变与因果性

系统定义为输入序列到输出序列的映射，记作 $y[n] = T\{x[n]\}$。三个关键性质：

- **线性**：$T\{a x_1[n] + b x_2[n]\} = a\,T\{x_1[n]\} + b\,T\{x_2[n]\}$
- **时不变**：$y[n - n_0] = T\{x[n - n_0]\}$，即延迟输入对应当地延迟输出
- **因果性**：输出仅依赖当前及过去的输入，$y[n]$ 不依赖 $x[n+1], x[n+2], \dots$

同时满足线性与时不变性的系统称为 **LTI 系统**，它是本章以及后续所有滤波器分析的核心对象。

### 2.2 冲激响应与 LTI 系统的完全表征

**冲激响应** $h[n]$ 定义为系统对单位脉冲的响应：

$$
\delta[n] \xrightarrow{\ \text{LTI}\ } h[n]
$$

由于"任何输入都可分解为移位脉冲的叠加"，且 LTI 系统对叠加是线性、时不变的，因此输出由输入与 $h[n]$ 的卷积唯一确定。**一个 LTI 系统完全由其冲激响应 $h[n]$ 刻画**，无需更复杂的模型。

## 3. 线性卷积

### 3.1 卷积公式

LTI 系统的输出为输入与冲激响应的线性卷积：

$$
y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k]\, h[n-k]
$$

卷积满足下列代数性质：

| 性质 | 表达式 |
|-----|-------|
| 交换律 | $x[n] * h[n] = h[n] * x[n]$ |
| 结合律 | $(x * h_1) * h_2 = x * (h_1 * h_2)$ |
| 分配律 | $x * (h_1 + h_2) = x * h_1 + x * h_2$ |

物理意义：把输入分解为一系列单位脉冲，系统输出就是各脉冲响应按对应强度加权后叠加的结果。这也是"滤波器=卷积"这一工程直觉的数学由来。

### 3.2 卷积的图解法步骤

对两个有限长序列求卷积，可按以下步骤：

1. 变量代换：写出 $x[k]$ 与 $h[k]$
2. 折叠：对 $h[k]$ 反折得 $h[-k]$
3. 平移：平移 $n$ 得 $h[n-k]$
4. 相点乘：对固定 $n$，将 $x[k]$ 与 $h[n-k]$ 逐点相乘
5. 求和：对 $k$ 求和得 $y[n]$

### 3.3 有限长序列卷积的长度

两个长度分别为 $L$ 与 $M$ 的序列，卷积结果长度为

$$
L + M - 1
$$

有限长卷积可用"竖式乘加"或列表法（多项式乘法方式）直接计算，工程上则是交由乘累加（MAC）单元在硬件中完成。

## 4. 差分方程

### 4.1 常系数线性差分方程

因果 LTI 系统常用 $N$ 阶常系数线性差分方程描述：

$$
\sum_{k=0}^{N} a_k\, y[n-k] = \sum_{k=0}^{M} b_k\, x[n-k]
$$

它是连续系统微分方程在离散域的对应。当 $N=0$（无反馈、全 $a_k$ 中除 $a_0$ 外为零）时为 FIR，否则为 IIR。

### 4.2 求解方法

- **递推法**：给定初始条件逐点代入，向前递推
- **零输入 + 零状态分解**：分别求系统自由响应与强迫响应再叠加
- **Z 变换法**：将差分方程取 Z 变换化为代数方程求解（见 [20.3 Z变换](20.3-Z变换.md)），这是工程上最系统的方法

需要注意：只有当系统初始条件为零（或系统因果稳定）时，差分方程的解才与冲激卷积 $x[n]*h[n]$ 等价。

### 4.3 滑动平均与延迟线

差分方程最常见的两个特例是：

**滑动平均（FIR 低通）**：

$$
y[n] = \frac{1}{M}\sum_{k=0}^{M-1} x[n-k]
$$

**一阶递归（IIR 低通）**：

$$
y[n] = a\, y[n-1] + (1-a)\, x[n]
$$

前者无反馈、必然稳定；后者含反馈、输出依赖历史输出，是后续 IIR 滤波的基础。

## 5. 工程 / 典型应用

- **滑动平均滤波器**：最简单的 FIR 低通，广泛用于传感器降噪与信号平滑
- **数字差分器 / 累加器**：一阶差分 $y[n]=x[n]-x[n-1]$、累加 $y[n]=y[n-1]+x[n]$，对应连续微积分算子
- **回声与混响模型**：$y[n]=x[n]+a\, x[n-D]$ 即离散延迟线的工程应用
- **卷积滤波实现**：硬件中用乘累加（MAC）单元实时计算卷积，为 [20.11 DSP硬件结构](20.11-DSP硬件结构.md) 奠定基础

## 小结

- 序列 $\{x[n]\}$ 是离散信号的基本表示，单位脉冲 $\delta[n]$ 可在分解信号中替代连续冲激
- LTI 系统完全由冲激响应 $h[n]$ 描述，输出为其与输入的线性卷积
- 卷积满足交换律、结合律、分配律，有限长卷积结果长度为 $L+M-1$
- 因果 LTI 系统常用常系数线性差分方程描述，可递推或经 Z 变换求解
- 滑动平均与一阶递归分别给出 FIR、IIR 的最简单实例
