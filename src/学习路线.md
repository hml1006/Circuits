# 学习路线

这是一本“核心主线 + 方向分流”的自学教程。**不建议从第一页线性读到最后一页**：先用本页选定路线，再按编号顺序阅读；路线之外的章节按需查阅。

## 三个阶段

| 阶段 | 目标 | 内容 |
|---|---|---|
| 一、打基础 | 建立电路直觉与数学工具 | 1.1–1.33（数学、概率、信号与系统、电磁学、电路基础、电路原理） |
| 二、两大主干 | 打通模拟或数字一条主线 | 模拟：2.1–2.16；数字：3.1–3.10 |
| 三、方向分流 | 进入 IC、系统或电力电子 | 第四篇 / 第五篇 / 第二篇后半 |

核心主线是 `1.1–1.33 → （模拟 2.1–2.16 或数字 3.1–3.10）`。完成后再从下面四条路线中选一条。

## 检查点项目

每完成一篇，至少做一个能运行/能画出来的小项目：

| 篇 | 检查点 |
|---|---|
| 第一篇 | 用 SPICE 验证戴维南等效与一阶 RC 暂态（1.23、1.24） |
| 第二篇 | 设计并仿真两级运放（2.1–2.16），或 Buck 变换器（2.21–2.24） |
| 第三篇 | 用 Verilog 写计数器/状态机，再做单周期 CPU（3.1–3.16） |
| 第四篇 | 跑通 RTL → 综合 → STA 小流程（4.5–4.12），或写一个 UVM testbench（4.19–4.23） |
| 第五篇 | 设计 FIR 滤波器并做 QPSK 链路仿真（5.6、5.17） |
| 第六篇 | 完成 6.3 中至少 2 个实验，画出 PCIe/DDR 的协议分层与典型拓扑（6.1–6.2） |

## 可选与跳过

- **1.3 量子力学基础**：只有 2.1 半导体物理和 4.3 CMOS 器件物理强依赖；纯数字方向可先跳过。
- **2.17–2.20 射频基础**：做 RFIC、SI/EMC 必读；纯数字/电源方向可略读。
- **4.17 先进技术、4.44–4.47 RFIC、4.48–4.51 MEMS**：方向性很强，按需阅读。
- **5.24–5.33 自动控制**：做控制系统、机器人、电机控制时再读；只做通信算法可跳过。
- **6.8–6.12 方向选修**：天线、电力系统、光电子、嵌入式/OS、可靠性；按目标岗位选读，不必全做。

## 阅读建议

1. 遇到不认识的数学符号，先回 [1.1 数学基础](01-基础与电路分析/大学物理基础/1.1-数学基础.md) 查，不要卡住。
2. 每章先看“前置知识”，确认缺口；读完做“自测清单”，答不上来就回到对应小节。
3. 第一遍允许跳过推导，只抓结论和适用条件；第二遍再补推导。
4. 不要同时开三条路线；选一条走到能做出检查点项目，再扩展。
5. 每完成一篇，配合 [6.3 实验与项目手册](06-专题与实战/专题/6.3-实验与项目手册.md) 做一个实验，并用 [6.4 核心习题与答案](06-专题与实战/专题/6.4-核心习题与答案.md) 检查计算能力。
