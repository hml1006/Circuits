# 4.31.2 PLL全集成设计与进阶专题

> **本章定位**：面向全集成 PLL 实现，处理电源噪声、衬底耦合、匹配对称、屏蔽、去耦和电感版图等进阶设计问题。

> **前置知识**：必需 [4.31.1 PLL环路模型与噪声](4.31.1-PLL环路模型与噪声.md) 与 [4.14 版图设计](../芯片设计/4.14-版图设计.md)；推荐 [2.13 噪声分析与低噪声设计](../../02-模拟与硬件工程/模拟电路/2.13-噪声分析与低噪声设计.md)。

## 1. 全集成PLL设计考虑

### 1.1 电源噪声抑制

**电源噪声来源**：

1. **数字电路开关噪声**：$\Delta I$ 噪声、地弹（ground bounce）
2. **电源纹波**：DC-DC转换器的开关噪声
3. **衬底耦合**：通过衬底耦合的噪声

**电源噪声对PLL的影响**：

- VCO控制电压被调制，产生相位噪声
- 电荷泵电流被调制，产生杂散
- 分频器时序抖动

**抑制技术**：

1. **电源去耦**：
   - 大电容（10~100nF）：滤除低频噪声
   - 小电容（0.1~1nF）：滤除高频噪声
   - 片内去耦：靠近敏感电路放置

2. **稳压器（LDO）**：
   - 为VCO和电荷泵提供干净的电源
   - PSRR > 40dB @ 1MHz

3. **差分结构**：
   - 使用差分VCO、差分电荷泵
   - 抑制共模电源噪声

4. **电源域隔离**：
   - 模拟电源（AVDD）和数字电源（DVDD）分离
   - 使用磁珠或电感隔离

### 1.2 衬底噪声隔离

**衬底耦合机制**：

1. **电阻耦合**：通过衬底电阻的电流注入
2. **电容耦合**：通过结电容的电压耦合
3. **闩锁效应**：大信号触发寄生SCR

**隔离技术**：

| 技术 | 隔离度 | 面积 | 复杂度 |
|-----|--------|------|--------|
| **保护环（Guard Ring）** | 10~20dB | 中 | 低 |
| **深N阱（DNW）** | 20~30dB | 大 | 中 |
| **SOI工艺** | >40dB | 小 | 高 |
| **物理隔离** | 30~40dB | 很大 | 高 |

**保护环设计**：

- **P+保护环**：包围NMOS，接地
- **N+保护环**：包围PMOS，接电源
- **双保护环**：P+/N+交替，提高隔离度

### 1.3 版图考虑

**关键版图技术**：

1. **匹配设计**：
   - 电荷泵电流源：共质心（common centroid）布局
   - 差分对：交叉匹配
   - 使用dummy器件保证边缘一致性

2. **对称性**：
   - 差分信号路径对称
   - 电源和地对称分布
   - 减少寄生不对称

3. **屏蔽**：
   - 敏感节点使用地屏蔽（ground shield）
   - 电感下方避免走线
   - 使用屏蔽环隔离敏感电路

4. **去耦电容布局**：
   - 靠近电源引脚放置
   - 分散布局，避免谐振
   - 使用MIM电容提高Q值

5. **电感布局**：
   - 使用顶层厚金属
   - 对称走线（8字形或中心抽头）
   - 远离衬底，减少损耗

## 小结

1. **电源噪声抑制**：数字开关、稳压器纹波和衬底耦合会调制 VCO、电荷泵和分频器，可通过去耦、LDO、差分结构及电源域隔离降低影响。

2. **衬底隔离**：保护环、深 N 阱、SOI 和物理隔离在隔离度、面积及工艺复杂度之间提供不同取舍。

3. **版图实现**：电流源和差分对需要匹配对称，敏感节点应屏蔽并合理去耦，电感则要利用厚金属、对称走线和远离衬底来降低损耗。

2. 去耦、LDO、差分结构和电源域隔离分别针对哪类噪声？
3. 保护环、深 N 阱、SOI 与物理隔离的成本和效果有何差异？
4. 为什么电荷泵电流源、差分信号路径和电感版图需要特别的匹配与对称？
5. 全集成 PLL 的电源、衬底和版图设计如何共同影响环路指标？
