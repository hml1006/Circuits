# 电路学习教程

从中学电学一路走到集成电路与 CPU 设计的自学教程。全书按 **6 篇、183 个章节页** 组织，覆盖电路分析、模拟/数字电路、芯片设计、信号处理、通信与控制等方向。

## 适合谁

- 想从零系统学习电路，但不想在庞杂资料里迷路的人；
- 电子/微电子/计算机相关专业，需要补全“电路 → 芯片”知识链的人；
- 已会某一方向（如数字逻辑），想补模拟、射频或 IC 实现的人。

默认起点是中学物理的电学部分；数学工具集中在 [1.1 数学基础](01-基础与电路分析/大学物理基础/1.1-数学基础.md)，遇到不熟悉的符号可以随时回查。

## 怎么用

1. **先读 [学习路线](学习路线.md)**。全书采用“最小公共核心 + 方向主线 + 进阶选修”，不要求从第一页线性读到最后一页。
2. 选定一条路线，按路线列出的顺序阅读；编号用于稳定检索，不代表唯一学习顺序。
3. 每章开头区分 **必需先修与推荐先修**，章末有 **小结/本章要点**、**自测清单** 和 **下一章**。自测题答不上来时，回到对应小节重读。
4. 每个方向至少完成一个可自检的练习或小项目，保留过程、结果和误差分析，避免只看不动手。

## 章节约定

- 编号 `P.N`：`P` 为篇号，`N` 为篇内序号；编号是稳定标识，不代表唯一阅读顺序。
- 长章拆分可使用 `P.N.M` 子编号，例如 `4.29.1`、`4.37.2`；连续系列也可用“（一）（二）……”区分，例如 `4.19–4.23`。
- 章内小节统一用 `## 1.`、`## 2.` 编号；`小结`、`自测清单` 不编号。
- 代码块以 Verilog/SystemVerilog、SPICE、Python 为主；公式使用 KaTeX。

## 本地构建

```bash
mdbook serve      # 本地预览，默认 http://localhost:3000
mdbook build      # 生成静态站点到 book/
```

需要安装 [mdbook](https://rust-lang.github.io/mdBook/) 与 KaTeX 预处理器（项目已配置 `[preprocessor.katex]`）。
