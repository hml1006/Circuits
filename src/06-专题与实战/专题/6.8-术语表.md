# 6.8 术语表

> **本章定位**：把全书高频术语按方向汇总，便于查阅和面试前快速复习。

> **前置知识**：无；建议在读完对应章节后回查。

## 1. 电路与电磁

| 术语 | 英文 | 解释 |
|---|---|---|
| 参考方向 | reference direction | 人为假定的电流/电压正方向 |
| 关联参考方向 | associated reference direction | 电流从电压正极流入 |
| KCL | Kirchhoff's Current Law | 节点电流代数和为零 |
| KVL | Kirchhoff's Voltage Law | 回路电压代数和为零 |
| 戴维南定理 | Thevenin's theorem | 线性含源二端网络可等效为电压源串联电阻 |
| 诺顿定理 | Norton's theorem | 线性含源二端网络可等效为电流源并联电阻 |
| 叠加定理 | superposition | 线性电路中各源单独作用响应之和 |
| 相量 | phasor | 用复数表示正弦量的幅度与相位 |
| 阻抗 | impedance | 复频域中电压与电流之比 |
| 谐振 | resonance | 感抗与容抗相互抵消，阻抗呈纯阻性 |
| 品质因数 | quality factor | 谐振电路储能与每周期耗能之比 |
| 三相电路 | three-phase circuit | 三个幅值相等、相位互差 120° 的电源系统 |
| 双口网络 | two-port network | 用 Z/Y/H/S 等参数描述输入输出关系 |
| 拉普拉斯变换 | Laplace transform | 把时域微分方程变为 s 域代数方程 |
| 傅里叶变换 | Fourier transform | 把信号分解为不同频率的正弦分量 |
| SPICE | Simulation Program with Integrated Circuit Emphasis | 用网表和器件模型进行电路数值仿真 |
| 网表 | netlist | 描述器件、节点连接及分析指令的文本 |
| 直流工作点 | DC operating point | 直流稳态下的节点电压与支路电流 |
| 数字万用表 | digital multimeter (DMM) | 测量电压、电流、电阻等电量的仪表 |
| 示波器 | oscilloscope | 显示电压随时间变化并测量波形参数的仪器 |
| 逻辑分析仪 | logic analyzer | 按阈值采集多路数字信号并可解码协议的仪器 |
| 测量不确定度 | measurement uncertainty | 表征测量结果分散程度的参数 |

## 2. 模拟电路

| 术语 | 英文 | 解释 |
|---|---|---|
| 本征半导体 | intrinsic semiconductor | 未掺杂的纯净半导体 |
| 空穴 | hole | 价带中缺少电子形成的等效正电荷载流子 |
|  PN 结 | PN junction | P 型与 N 型半导体交界形成的耗尽层 |
| 二极管 | diode | 单向导电的两端器件 |
| BJT | bipolar junction transistor | 电流控制的双极型晶体管 |
| MOSFET | metal-oxide-semiconductor FET | 电压控制的场效应管 |
| 跨导 | transconductance | $g_m=\partial I_D/\partial V_{GS}$ |
| 小信号模型 | small-signal model | 在工作点附近线性化得到的等效电路 |
| 共射/共源 | common-emitter/common-source | 输入在基极/栅极、输出在集电极/漏极的放大组态 |
| 频率响应 | frequency response | 增益与相位随频率的变化 |
| 增益带宽积 | gain-bandwidth product | 开环增益与带宽的乘积，运放常数 |
| 负反馈 | negative feedback | 输出反相送回输入，降低增益、改善线性与带宽 |
| 相位裕度 | phase margin | 增益为 1 时相位距 -180° 的余量 |
| 运放 | operational amplifier | 高增益差分放大器，配合反馈实现各种函数 |
| 失调电压 | input offset voltage | 使输出为零所需的输入差分电压 |
| 共模抑制比 | CMRR | 差模增益与共模增益之比 |
| 电源抑制比 | PSRR | 差模增益与电源到输出增益之比 |
| 压摆率 | slew rate | 运放输出最大变化速率 |
| 噪声系数 | noise figure | 输入 SNR 与输出 SNR 之比 |

## 3. 数字电路

| 术语 | 英文 | 解释 |
|---|---|---|
| 数制 | number system | 二进制、八进制、十六进制等表示法 |
| 补码 | two's complement | 有符号整数的常用编码 |
| 逻辑门 | logic gate | 实现与、或、非等布尔函数的电路 |
| 组合逻辑 | combinational logic | 输出只取决于当前输入 |
| 时序逻辑 | sequential logic | 输出依赖当前输入与历史状态 |
| 锁存器 | latch | 电平敏感存储单元 |
| 触发器 | flip-flop | 时钟边沿触发的存储单元 |
| 建立时间 | setup time | 数据在时钟沿前必须稳定的时间 |
| 保持时间 | hold time | 数据在时钟沿后必须保持的时间 |
| 亚稳态 | metastability | 触发器采样到临界电平时输出不确定 |
| 状态机 | finite state machine | 由状态、输入、次态与输出组成 |
| 独热编码 | one-hot encoding | 每个状态用一位表示 |
| 格雷码 | Gray code | 相邻码字只差一位，降低翻转错误 |
| 竞争冒险 | race/hazard | 组合逻辑中因路径延迟产生的毛刺 |
| 可编程逻辑 | PLD/FPGA | 可通过配置实现自定义逻辑的器件 |
| ADC/DAC | analog-to-digital/digital-to-analog converter | 模拟与数字信号转换器 |
| 量化 | quantization | 把连续幅度映射到离散电平 |
| 采样定理 | Nyquist theorem | 采样率需大于信号最高频率的两倍 |
| 过采样率 | oversampling ratio (OSR) | 采样率与奈奎斯特率之比，常写 $OSR=f_s/(2B)$ |
| 有效位数 | effective number of bits (ENOB) | 由实际 SNDR 换算的等效 ADC 位数 |
| DNL/INL | differential/integral nonlinearity | ADC/DAC 的步长偏差及其累积误差 |

|---|---|---|

| 氧化 | oxidation | 生长二氧化硅绝缘层 |

| CMOS | complementary MOS | NMOS 与 PMOS 互补的工艺 |

## 小结

- 术语表按电路与测量、模拟、数字与数据转换、芯片设计/签核/测试、体系结构、DSP/通信/控制、封装/可靠性分组。
- 面试前建议先看英文缩写，再回想中文定义与一个典型应用；同一缩写要结合方向辨析，例如 DFT 在 DSP 与芯片测试中含义不同。
- 遇到新术语时，回到对应章节看上下文，不要只背一句话。

## 自测清单

1. 能否看到英文缩写立即说出中文与一个应用？
2. 能否用 SPICE、网表、直流工作点和测量不确定度说明“手算—仿真—实测”的闭环？
3. 模拟电路中的 $g_m$、增益、相位裕度、噪声系数能否用一句话解释？
4. 数字电路中的 setup/hold、亚稳态、状态机，以及 OSR、ENOB、DNL/INL 能否举例？
5. 能否区分 Lint、CDC、RDC、DFM/DFY，并说明签核证据与 waiver 的作用？
6. 能否把 DFT、ATPG/BIST、ATE、CP/FT/SLT、bring-up、硅后验证串成测试与首片调试流程？
7. MIMO、OFDM、QAM、BER、链路预算能否串成一条通信链路？
8. Shmoo、binning、SPC 分别回答什么问题，为什么不能互相替代？
