# 电路学习教程

本教程系统性地涵盖了从中学电路到芯片设计的完整知识体系，共分为 20 个章节：

- **〇、大学物理基础** — 数学基础（复数相量、微分方程、矩阵）、电磁学、量子力学
- **一、物理·电路基础** — 电荷、电流、电压、电阻、欧姆定律、串并联电路、电功率、家庭电路
- **二、物理·电路进阶** — 恒定电流、电容、电感、交流电、变压器、电磁感应、电动机与发电机
- **三、电路原理** — 电路基本定律、电阻电路分析、电路定理、暂态分析、正弦稳态、三相电路
- **四、模拟电路** — 半导体物理、二极管、BJT、FET、运放、功放、滤波器、振荡器、稳压电源
- **五、数字电路** — 数制与编码、逻辑代数、逻辑门、组合逻辑、触发器、时序逻辑、存储器、PLD、ADC/DAC、数字系统设计基础
- **六、芯片设计** — 半导体工艺、CMOS器件、RTL设计（含FPGA实践）、逻辑综合、物理设计、时序分析、DFT、SoC
- **七、射频与微波电路基础** — 传输线、阻抗匹配与 Smith 圆图、S 参数、微带线与带状线（微波无源电路基础）
- **八、电力电子** — 晶闸管与现代功率器件（MOSFET/IGBT/SiC/GaN）、逆变器、DC-DC 变换、PWM、电机驱动
- **九、信号完整性与电磁兼容** — 信号完整性、EMC/EMI
- **十、模拟IC设计** — 运放设计、带隙基准源、PLL、开关电容电路
- **十一、数字验证方法学** — UVM、形式验证
- **十二、混合信号IC设计** — 混合信号设计、电源管理IC
- **十三、存储器IC设计**
- **十四、封装与热设计**
- **十五、数据转换器IC设计**
- **十六、RFIC设计**
- **十七、MEMS基础**
- **十八、计算机组成原理** — 从逻辑门到单周期处理器、流水线处理器（超标量CPU的基石）
- **十九、CPU设计** — 超标量CPU微架构基础、存储层次与缓存一致性、现代CPU实现分析
