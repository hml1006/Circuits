# 电路学习教程

本教程系统性地涵盖了从电路基础到高级集成电路设计的知识体系，共分为 17 个章节：

- **一、物理·电路基础** — 电荷、电流、电压、电阻、欧姆定律、串并联电路、电功率、家庭电路
- **二、物理·电路进阶** — 恒定电流、电容、电感、交流电、变压器、电磁感应、电动机与发电机
- **三、电路原理** — 电路基本定律、电阻电路分析、电路定理、暂态分析、正弦稳态、三相电路
- **四、模拟电路** — 半导体物理、二极管、BJT、FET、运放、功放、滤波器、振荡器、稳压电源
- **五、数字电路** — 数制与编码、逻辑代数、逻辑门、组合逻辑、触发器、时序逻辑、存储器、PLD、ADC/DAC
- **六、芯片设计** — 半导体工艺、CMOS器件、RTL设计、逻辑综合、物理设计、时序分析、DFT、SoC
- **七、射频与高频电路** — 传输线、Smith圆图、S参数
- **八、电力电子** — 晶闸管、逆变器、PWM、电机驱动
- **九、信号完整性与电磁兼容** — 信号完整性、EMC/EMI
- **十、模拟IC设计** — 运放设计、带隙基准源、PLL、开关电容电路
- **十一、数字验证方法学** — UVM、形式验证
- **十二、混合信号IC设计** — 混合信号设计、电源管理IC
- **十三、存储器IC设计**
- **十四、封装与热设计**
- **十五、数据转换器IC设计**
- **十六、RFIC设计**
- **十七、MEMS基础**
