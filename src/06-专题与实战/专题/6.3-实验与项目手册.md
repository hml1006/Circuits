# 6.3 实验与项目手册

> **本章定位**：把前面各篇的知识变成可运行、可验收的动手项目；每个实验都给出环境、步骤、验收标准和报告模板。

> **前置知识**：按实验选择对应章节；建议先完成 [1.23 电路定理](../../01-基础与电路分析/电路原理/1.23-电路定理.md)、[3.10 数字系统设计基础](../../03-数字与计算机系统/数字电路/3.10-数字系统设计基础.md)、[4.5 RTL 设计（一）](../../04-集成电路设计/芯片设计/4.5-RTL设计-基础语法与建模.md) 中的至少一条主线。

## 2. Lab 1：戴维南等效与一阶 RC

**目标**：用 SPICE 验证 [1.23 电路定理](../../01-基础与电路分析/电路原理/1.23-电路定理.md) 与 [1.24 一阶电路暂态分析](../../01-基础与电路分析/电路原理/1.24-一阶电路暂态分析.md)。

**步骤**：

1. 搭一个含独立源与三个电阻的线性网络，用 `.op` 求开路电压与短路电流；
2. 用 `.tf` 或外加测试源求等效电阻；
3. 搭戴维南等效电路，对比原网络在负载上的电压/电流；
4. 搭 RC 充电电路，用 `.tran` 观察 $v_C(t)$；
5. 改变 $R$、$C$，验证 $\tau=RC$ 与 5$\tau$ 稳定准则。

**验收**：

- 原网络与等效电路在 3 个不同负载下的误差 < 2%；
- 波形读出 $\tau$ 与理论值误差 < 5%；
- 报告中给出网表、波形与误差表。

## 3. Lab 2：两级 CMOS 运放

**目标**：完成 [4.29 运算放大器设计](../../04-集成电路设计/模拟IC设计/4.29-运算放大器设计.md) 的最小闭环。

**步骤**：

1. 用理想元件搭五管 OTA + 共源第二级，设定尾电流与偏置；
2. 用 `.ac` 测开环增益、GBW、相位裕度；
3. 用 `.dc` 扫描输入共模范围与输出摆幅；
4. 用 `.tran` 测阶跃响应、压摆率、建立时间；
5. 用 `.noise` 测输入等效噪声；
6. 扫描补偿电容，观察相位裕度与带宽折中。

**验收**：

- 开环增益 ≥ 60 dB，相位裕度 ≥ 60°；
- 建立时间与理论估算同一量级；
- 报告解释补偿电容、尾电流、负载电容对指标的影响。

## 4. Lab 3：Buck 变换器

**目标**：理解 [2.21 晶闸管](../../02-模拟与硬件工程/电力电子/2.21-晶闸管-SCR与双向晶闸管-TRIAC.md)–[2.24 电机驱动基础](../../02-模拟与硬件工程/电力电子/2.24-电机驱动基础.md) 与 [4.34 电源管理 IC（一）](../../04-集成电路设计/混合信号IC设计/4.34-电源管理IC-概述与LDO.md) 的开关电源基础。

**步骤**：

1. 搭理想 Buck 电路，设置开关频率、占空比、电感、电容、负载；
2. 用 PWM 源驱动开关，观察电感电流与输出纹波；
3. 改变占空比，验证 $V_{out}\approx D V_{in}$；
4. 加入寄生电阻/电容，观察效率与纹波变化；
5. 用平均模型或小信号模型估算环路稳定性（可选）。

**验收**：

- 输出电压与占空比关系误差 < 5%；
- 纹波与电感电流斜率符合理论；
- 报告给出效率分解（导通、开关、驱动损耗）。

## 5. Lab 4：Verilog 计数器与状态机

**目标**：完成 [3.4 组合逻辑电路](../../03-数字与计算机系统/数字电路/3.4-组合逻辑电路.md)–[3.6 时序逻辑电路](../../03-数字与计算机系统/数字电路/3.6-时序逻辑电路.md) 的 RTL 实现。

**步骤**：

1. 写一个带使能、同步复位的 8 位计数器；
2. 写一个三段式状态机（如交通灯或序列检测）；
3. 写 testbench，覆盖复位、使能、边界值、非法状态；
4. 用 `iverilog`/`vvp` 跑仿真，GTKWave 看波形；
5. 用 Verilator lint 检查可综合性。

**验收**：

- 计数器在 255 后正确回绕；
- 状态机无锁死，非法状态有恢复路径；
- testbench 覆盖率达到预期，波形与断言通过。

## 6. Lab 5：单周期 CPU

**目标**：把 [3.11 从逻辑门到单周期处理器](../../03-数字与计算机系统/计算机组成原理/3.11-从逻辑门到单周期处理器.md) 变成可运行 RTL。

**步骤**：

1. 定义最小指令集（如 ADD、LOAD、STORE、BEQ、JAL）；
2. 实现 PC、指令存储器、寄存器堆、ALU、数据存储器、控制单元；
3. 写汇编测试程序与 testbench；
4. 跑通冒泡排序或斐波那契；
5. 用 GTKWave 检查取指、译码、执行、写回。

**验收**：

- 测试程序结果正确；
- 每条指令的周期数与设计一致；
- 报告中给出数据通路图与关键控制信号表。

## 7. Lab 6：RTL → 综合 → STA

**目标**：走通 [4.9 功能验证](../../04-集成电路设计/芯片设计/4.9-功能验证.md)–[4.12 时序分析](../../04-集成电路设计/芯片设计/4.12-时序分析.md) 的最小后端流程。

**步骤**：

1. 用 Yosys 把 RTL 综合到门级网表；
2. 用 OpenSTA 读入网表与时序约束（SDC）；
3. 报告 WNS、TNS、关键路径；
4. 修改 RTL 或约束，观察时序变化；
5. 可选：用 nextpnr/OpenROAD 做布局布线。

**验收**：

- 综合无 latch、无多驱动；
- STA 报告能定位关键路径；
- 报告解释 setup/hold 违例的原因与修法。

## 8. Lab 7：UVM 小平台

**目标**：完成 [4.19 UVM 验证方法学（一）](../../04-集成电路设计/数字验证方法学/4.19-UVM-概述与核心组件.md)–[4.23 UVM 验证方法学（五）](../../04-集成电路设计/数字验证方法学/4.23-UVM-实战与小结.md) 的最小验证环境。

**步骤**：

1. 为 Lab 4 的计数器定义 transaction；
2. 写 driver、monitor、sequencer、agent；
3. 写 scoreboard，比较 DUT 与参考模型；
4. 加覆盖率收集与随机激励；
5. 跑 1000 次回归，统计通过率。

**验收**：

- 随机激励下 scoreboard 无错误；
- 覆盖率报告包含功能覆盖率与代码覆盖率；
- 能复现并定位至少一个注入的 bug。

## 9. Lab 8：FIR 滤波与 QPSK 链路

**目标**：把 [5.6 FIR滤波器设计](../../05-信号、通信与控制/数字信号处理/5.6-FIR滤波器设计.md) 与 [5.17 数字调制](../../05-信号、通信与控制/通信原理/5.17-数字调制.md) 连成一条链路。

**步骤**：

1. 用窗函数法设计低通 FIR，画出幅频/相频；
2. 生成 QPSK 符号，经成型滤波、上变频、AWGN 信道；
3. 接收端做匹配滤波、定时恢复、载波恢复、判决；
4. 扫描 SNR，画 BER 曲线，与理论 QPSK 曲线对比；
5. 加入频偏/相噪，观察性能损失。

**验收**：

- FIR 阻带衰减满足设计指标；
- BER 曲线在 1–2 dB 内接近理论；
- 报告解释成型滤波、匹配滤波与同步的作用。

## 小结

- 8 个实验覆盖电路、模拟、电力电子、数字、CPU、后端、验证、DSP/通信。
- 每个实验都应有可复现的源码、波形、指标与误差分析。
- 实验报告的重点不是“结果好看”，而是“能解释为什么”。
