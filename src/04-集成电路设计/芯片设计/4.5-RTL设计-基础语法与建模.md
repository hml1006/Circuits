# 4.5 RTL 设计（一）Verilog 基础语法与建模

> **本章定位**：RTL 设计的第一组页面，先用 Verilog 建立可综合的硬件描述习惯。

> **前置知识**：必需 [3.1–3.8 数字电路基础](../../03-数字与计算机系统/数字电路/3.1-数制与编码.md) 与 [3.10 数字系统设计基础](../../03-数字与计算机系统/数字电路/3.10-数字系统设计基础.md)。

> 本页为《RTL 设计》系列第 1/4 页。

## 1. 概述

RTL（Register Transfer Level，寄存器传输级）设计是数字集成电路设计的核心环节，使用硬件描述语言（HDL）在寄存器传输级描述数字电路的行为与结构。

RTL 设计的本质是**描述寄存器之间的组合逻辑路径**：每个时钟沿触发时，数据从一组寄存器通过组合逻辑传输到下一组寄存器。

![RTL寄存器级示例](images/rtl-register-level-example.png)
该图以寄存器级示例示意RTL数据通路，数据在时钟沿驱动下经组合逻辑在寄存器组间传输。

### 三大硬件描述 / 构建语言

| 语言          | 类型               | 特点                                | 适用场景                    |
| ------------- | ------------------ | ----------------------------------- | --------------------------- |
| Verilog HDL   | 硬件描述语言       | 语法类似 C，IEEE 标准，业界最广泛   | 数字 IC 设计、FPGA 设计     |
| SystemVerilog | 硬件描述与验证语言 | Verilog 的超集，增加 OOP 和验证特性 | 复杂设计验证、UVM 测试平台  |
| Chisel        | 硬件构建语言       | 嵌入 Scala 的 DSL，参数化能力强     | 敏捷硬件设计、RISC-V 处理器 |

## 2. Verilog HDL 基础语法

### 2.1 模块与端口

模块（Module）是 Verilog 的基本设计单元，代表一个硬件模块：

```verilog
module module_name (
    input  wire       clk,
    input  wire       rst_n,
    input  wire [7:0] data_in,
    output reg  [7:0] data_out
);
    // 模块内部逻辑
endmodule
```

### 2.2 端口类型与方向

| 端口类型 | 关键字     | 说明                     |
| -------- | ---------- | ------------------------ |
| 输入端口 | `input`  | 只能从外部读取，不能赋值 |
| 输出端口 | `output` | 可以驱动外部信号         |
| 双向端口 | `inout`  | 既可输入也可输出（三态） |

### 2.3 注释

```verilog
// 单行注释
/* 多行注释 */
```

### 2.4 模块实例化

```verilog
// 按端口名连接（推荐）
my_module u_inst (
    .clk    (clk),
    .rst_n  (rst_n),
    .data_in(data_in),
    .data_out(data_out)
);

// 按端口顺序连接（不推荐，易出错）
my_module u_inst (clk, rst_n, data_in, data_out);
```

## 3. 数据类型

### 3.1 wire 类型

wire 表示连线，用于组合逻辑的输出，不能存储值：

```verilog
wire [7:0] sum;     // 8位宽连线
wire       flag;    // 1位宽连线
wire [31:0] addr;   // 32位地址总线
```

- wire 默认值为 `Z`（高阻态）
- wire 在 `assign` 语句中赋值
- wire 不能用在 `always` 块的左值

### 3.2 reg 类型

reg 表示寄存器（或变量），用于在 always 块中存储值。综合后可能是寄存器，也可能是连线：

```verilog
reg  [7:0] counter;  // 8位寄存器
reg        state;     // 1位状态寄存器
reg [31:0] mem [0:1023]; // 1024×32 位存储器
```

- reg 默认值为 `X`（未知态）
- reg 在 `always` 块中被赋值
- 综合工具根据赋值方式决定是否实现为寄存器

### 3.3 integer 类型

integer 用于循环和计算，综合为 32 位寄存器：

```verilog
integer i;
for (i = 0; i < 16; i = i + 1) begin
    // 循环展开
end
```

### 3.4 parameter / localparam 类型

parameter 用于定义常量，可在模块实例化时覆盖：

```verilog
parameter DATA_WIDTH = 8;  // 可被外部覆盖
localparam DEPTH = 16;     // 不能被外部覆盖
```

### 3.5 常用常量表示

```verilog
// 格式: [位宽]'[进制][数值]
8'b10101010     // 8位二进制
8'hAA           // 8位十六进制
8'd170          // 8位十进制
4'd15           // 4位十进制
1'b1            // 1位高电平
1'b0            // 1位低电平
```

## 4. 连续赋值（assign）

连续赋值用于描述组合逻辑，输入变化时输出立即更新：

```verilog
wire [3:0] a, b;
wire [4:0] sum;

assign sum = a + b;            // 加法器
assign y   = (sel) ? d1 : d0;  // 2选1多路选择器
assign full = (wr_ptr[ADDR_WIDTH] != rd_ptr[ADDR_WIDTH]) && 
              (wr_ptr[ADDR_WIDTH-1:0] == rd_ptr[ADDR_WIDTH-1:0]);
```

![连续赋值电路图](images/连续赋值电路图.svg)

**重要规则**：

- assign 的左值必须是 wire 类型
- 多个 assign 语句并行执行
- assign 语句不可综合时序逻辑

## 5. 过程块

### 5.1 always 块

always 块是 Verilog 中最常用的过程块，可描述时序逻辑和组合逻辑：

```verilog
// 时序逻辑（同步复位）
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        q <= 1'b0;
    else
        q <= d;
end

// 组合逻辑
always @(*) begin
    case (sel)
        2'b00: y = a;
        2'b01: y = b;
        2'b10: y = c;
        default: y = d;
    endcase
end
```

![过程块电路图](images/过程块电路图.svg)

### 5.2 敏感列表

| 敏感列表                                   | 说明                           |
| ------------------------------------------ | ------------------------------ |
| `always @(posedge clk)`                  | 时钟上升沿触发                 |
| `always @(negedge clk)`                  | 时钟下降沿触发                 |
| `always @(posedge clk or negedge rst_n)` | 时钟上升沿或异步复位           |
| `always @(*)`                            | 组合逻辑，所有输入信号变化触发 |

**注意事项**：

- 时序逻辑的敏感列表中不应包含除时钟和异步复位外的信号
- 组合逻辑使用 `@(*)` 自动推断敏感列表，避免漏加信号

### 5.3 initial 块

initial 块仅用于仿真，在 0 时刻执行一次：

```verilog
initial begin
    clk = 0;
    rst_n = 0;
    #100 rst_n = 1;
end
```

## 6. 阻塞赋值与非阻塞赋值

### 6.1 阻塞赋值（=）

阻塞赋值顺序执行，**先赋值后执行下一条**，用于组合逻辑：

```verilog
always @(*) begin
    b = a;
    c = b;  // c = a
end
```

![阻塞赋值电路图](images/阻塞赋值电路图.svg)

### 6.2 非阻塞赋值（<=）

非阻塞赋值并行执行，**所有赋值同时完成**，用于时序逻辑：

```verilog
always @(posedge clk) begin
    b <= a;
    c <= b;  // c = 旧值 b（上一个时钟沿的值）
end
```

![非阻塞赋值电路图](images/非阻塞赋值电路图.svg)

### 6.3 赋值规则总结

| 类型       | 符号       | 适用场景            | 执行方式               |
| ---------- | ---------- | ------------------- | ---------------------- |
| 连续赋值   | `assign` | 简单组合逻辑        | 输入变化立即更新       |
| 阻塞赋值   | `=`      | always 中的组合逻辑 | 顺序执行，立即更新     |
| 非阻塞赋值 | `<=`     | always 中的时序逻辑 | 并行执行，块结束时更新 |

### 6.4 常见错误示例

```verilog
// 错误：时序逻辑使用阻塞赋值
always @(posedge clk) begin
    q = d;  // 可能产生意外的行为
end

// 正确：时序逻辑使用非阻塞赋值
always @(posedge clk) begin
    q <= d;
end

// 错误：同一信号在多个 always 块中赋值
always @(posedge clk) q <= a;
always @(posedge clk) q <= b;  // 错误！多驱动
```

## 7. 时序逻辑建模

### 7.1 寄存器（D 触发器）

**RTL 代码**：

```verilog
// D 触发器（同步复位）
always @(posedge clk) begin
    if (!rst_n)
        q <= 1'b0;
    else
        q <= d;
end

// D 触发器（异步复位）
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        q <= 1'b0;
    else
        q <= d;
end
```

![D触发器电路图](images/D触发器电路图.svg)

**综合结果**：D 触发器由两个 D 锁存器主从级联构成。每个时钟上升沿，输入 D 被采样到输出 Q。

### 7.2 计数器

**RTL 代码**：

```verilog
// 模 16 计数器
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        cnt <= 4'b0;
    else if (cnt == 4'd15)
        cnt <= 4'b0;
    else
        cnt <= cnt + 1'b1;
end

// 带使能的计数器
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        cnt <= 4'b0;
    else if (en)
        cnt <= cnt + 1'b1;
end
```

![计数器电路图](images/计数器电路图.svg)

**综合结果**：4 个 D 触发器级联，每个触发器的输出连接到加法器，加法器输出反馈回触发器输入。

### 7.3 移位寄存器

**RTL 代码**：

```verilog
// 8 位移位寄存器
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        shift_reg <= 8'b0;
    else
        shift_reg <= {shift_reg[6:0], data_in};
end
```

![移位寄存器电路图](images/移位寄存器电路图.svg)

**综合结果**：8 个 D 触发器串联，每个触发器的输出 Q 连接到下一个触发器的输入 D。

### 7.4 带加载的寄存器

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        data_reg <= 8'b0;
    else if (load)
        data_reg <= data_in;
    // 无 else 时保持原值
end
```

## 8. 组合逻辑建模

### 8.1 使用 assign

```verilog
assign y = (a & b) | (c & d);  // 与或组合
assign sum = a + b;              // 加法器
assign y = s ? d1 : d0;          // 多路选择器
```

### 8.2 使用 always @(*)

```verilog
always @(*) begin
    case (sel)
        2'b00: y = a;
        2'b01: y = b;
        2'b10: y = c;
        2'b11: y = d;
    endcase
end
```

### 8.3 全加器

**RTL 代码**：

```verilog
module full_adder (
    input  a, b, cin,
    output s, cout
);
    assign s    = a ^ b ^ cin;
    assign cout = (a & b) | (a ^ b) & cin;
endmodule
```

![全加器电路图](images/全加器电路图.svg)

### 8.4 组合逻辑电路

![组合逻辑电路图](images/组合逻辑电路图.svg)

**多路选择器和加法器是组合逻辑中最常用的模块**。多路选择器实现数据选择，加法器实现算术运算。

### 8.5 避免锁存器（Latch）

**错误示例**（产生锁存器）：

```verilog
always @(*) begin
    if (en)
        q = d;
    // 缺少 else 分支，en=0 时 q 保持原值 → 综合出锁存器
end
```

**正确示例**：

```verilog
always @(*) begin
    if (en)
        q = d;
    else
        q = 1'b0;  // 所有分支都有赋值
end
```

## 9. 行为级与结构化建模

### 9.1 行为级建模

描述电路的功能行为，不关心具体结构：

```verilog
always @(posedge clk) begin
    if (en)
        data_out <= data_in;
end
```

### 9.2 结构化建模

实例化底层模块，描述电路的层次结构：

```verilog
module top (
    input  clk, rst_n,
    input  [7:0] a, b,
    output [8:0] sum
);
    wire [7:0] a_reg, b_reg;
  
    reg_8bit u_reg_a (.clk(clk), .rst_n(rst_n), .d(a), .q(a_reg));
    reg_8bit u_reg_b (.clk(clk), .rst_n(rst_n), .d(b), .q(b_reg));
    adder_8bit u_adder (.a(a_reg), .b(b_reg), .sum(sum));
endmodule
```
