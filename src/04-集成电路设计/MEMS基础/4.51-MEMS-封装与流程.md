> **前置知识**：本组为**方向选修**；学习本章必需 [4.50 MEMS 基础（三）](4.50-MEMS-执行器与谐振器.md)。

## 1. MEMS封装

MEMS 封装与 IC 封装有本质区别：MEMS 芯片包含**可动的机械结构**，封装必须保护这些结构在制造、运输和使用过程中不受损害，同时允许其与外部环境交互（如压力传感器需与大气连通，麦克风需声学通路）。

### 1.1 MEMS封装的特殊挑战

| 挑战 | 说明 |
|------|------|
| **释放孔/防粘连** | 释放后结构裸露，键合线/塑封料可能进入 |
| **机械保护** | 可动结构在塑封注塑压力下可能变形或断裂 |
| **真空封装** | 高 Q 谐振器/陀螺仪需真空环境 |
| **气密性** | 湿气进入导致腐蚀、粘连、性能退化 |
| **应力隔离** | 封装应力传递到芯片导致零偏/灵敏度漂移 |
| **环境交互** | 压力/气体/声学传感器需与外界连通 |

### 1.2 晶圆级封装（Wafer Level Packaging, WLP）

在晶圆级将 MEMS 结构密封，是最理想的封装方式：

```
MEMS 晶圆（含可动结构）+ 帽晶圆（Cap Wafer）→ 键合 → 切割 → 单颗封装
```

**优势**：

- 在切割前即完成密封，保护可动结构
- 每颗芯片独立密封，可靠性高
- 与标准 IC 封装流程兼容

### 1.3 硅帽封装（Cap Wafer）

最成熟的 MEMS WLP 方案：

1. **MEMS 晶圆**：完成 MEMS 结构加工和释放
2. **帽晶圆**：刻蚀空腔（对应 MEMS 结构位置）
3. **键合**：帽晶圆与 MEMS 晶圆通过玻璃焊料/阳极键合密封

键合方式选择：

| 键合方式 | 气密性 | 真空度 | 成本 | 适用 |
|---------|--------|--------|------|------|
| 玻璃焊料 | 好 | 中（~1 Torr） | 中 | 通用 MEMS |
| 阳极键合 | 极好 | 好（~0.1 Torr） | 中 | 压力传感器 |
| 共晶键合 | 极好 | 好（~0.01 Torr） | 高 | 陀螺仪、谐振器 |
| 金属扩散键合 | 极好 | 极好（<0.001 Torr） | 高 | 高 Q 谐振器 |

### 1.4 真空封装（Vacuum Packaging）

高 Q MEMS 谐振器和陀螺仪需真空封装以降低空气阻尼：

$$Q_{air} = \frac{\rho h \omega}{\mu}\cdot\frac{d}{L}$$

其中 $\mu$ 为空气粘度，$d$ 为间隙，$L$ 为特征长度。

| 封装气压 | Q 值（典型悬臂梁） | 应用 |
|---------|-------------------|------|
| 大气压 (760 Torr) | 10~100 | 加速度计、压力传感器 |
| 1~10 Torr | 100~1000 | 麦克风 |
| 0.01~0.1 Torr | 1000~10000 | 陀螺仪 |
| < 0.001 Torr | > 10000 | 谐振器、滤波器 |

**真空维持**：封装内常放置**吸气剂（Getter）**材料（如 Ti、ZrVFe 合金），持续吸收泄漏和释出的气体，维持长期真空度。

### 1.5 MEMS封装类型

| 封装类型 | 描述 | 典型应用 |
|---------|------|---------|
| **预成型陶瓷封装** | 金属盖密封陶瓷基板，MEMS 芯片粘在基板上 | 高可靠性（汽车、航天） |
| **塑封 QFN/LGA** | 硅帽保护 MEMS 后标准塑封 | 消费级传感器 |
| **晶圆级芯片规模封装（WLCSP）** | 晶圆级密封 + RDL + 焊球 | 超小型传感器 |
| **系统级封装（SiP）** | MEMS + CMOS + 无源器件共封装 | IMU、麦克风 |
| **引线框架封装** | 传统引线键合，MEMS 用硅帽保护 | 低成本压力传感器 |

## 2. MEMS设计流程

MEMS 设计是一个**多物理场、多尺度**的协同设计过程，涉及机械、电学、流体、热学等多学科交叉。

### 2.1 系统级设计（等效电路建模）

将 MEMS 器件用等效电路模型描述，在电路仿真器中进行系统级仿真：

| 机械量 | 电学等效 | 量纲关系 |
|--------|---------|---------|
| 力 $F$ | 电压 $V$ | [N] ↔ [V] |
| 速度 $v$ | 电流 $I$ | [m/s] ↔ [A] |
| 位移 $x$ | 电荷 $Q$ | [m] ↔ [C] |
| 质量 $m$ | 电感 $L$ | [kg] ↔ [H] |
| 刚度 $1/k$ | 电容 $C$ | [m/N] ↔ [F] |
| 阻尼 $c$ | 电阻 $R$ | [N·s/m] ↔ [Ω] |

优势：可在 SPICE/Cadence 中与电路协同仿真，快速迭代。

### 2.2 器件级仿真（有限元分析 FEM）

对 MEMS 结构进行精确的**多物理场耦合仿真**：

| 仿真软件 | 厂商 | 特点 |
|---------|------|------|
| **COMSOL Multiphysics** | COMSOL | 多物理场耦合，易用 |
| **ANSYS Mechanical** | Ansys | 结构力学强 |
| **CoventorWare** | Coventor（Lam Research） | MEMS 专用，工艺仿真集成 |
| **IntelliSuite** | IntelliSense | MEMS 专用，含工艺仿真 |
| **ABAQUS** | Dassault | 非线性力学 |

**典型仿真类型**：

| 仿真类型 | 目的 | 关键输出 |
|---------|------|---------|
| 静力学分析 | 挠度、应力、刚度 | 位移场、应力分布 |
| 模态分析 | 固有频率、模态形状 | 各阶频率、振型 |
| 谐响应分析 | 频域响应 | 幅频/相频特性 |
| 瞬态分析 | 时域动态响应 | 时间-位移曲线 |
| 热力学分析 | 温度分布、热应力 | 温度场、热变形 |
| 流固耦合 | 压膜阻尼 | Q 值、阻尼系数 |

### 2.3 工艺级仿真（Process Simulation）

模拟 MEMS 工艺加工过程，预测实际结构的几何形状和材料特性：

| 工具 | 用途 |
|------|------|
| **Sentaurus Process** | 硅工艺仿真（氧化、扩散、注入、刻蚀） |
| **CoventorWare SEMulator3D** | MEMS 工艺3D建模 |
| **VisualTAPAS** | 各向异性腐蚀仿真 |

工艺仿真可预测：刻蚀轮廓、侧壁形貌、残余应力分布、层间对准误差等。

### 2.4 版图设计

MEMS 版图设计与 IC 版图有显著差异：

| 方面 | IC 版图 | MEMS 版图 |
|------|---------|----------|
| **设计规则** | 统一 DRC | 无标准 DRC，需工艺定制 |
| **关键尺寸** | 晶体管尺寸 | 梁宽/厚/间距、梳齿参数 |
| **对称性** | 电流匹配 | 力学对称（热/应力对称） |
| **锚点设计** | 无 | 关键——影响刚度和应力 |
| **释放孔** | 无 | 需设计释放孔（加速腐蚀液进入） |
| **刻蚀补偿** | 无 | 凸角补偿（各向异性腐蚀） |

### 2.5 掩模制造与流片

完整的 MEMS 制造流程：

```
设计完成 → 版图输出 (GDSII) → 掩模制造 → 晶圆加工 → 划片 → 封装 → 测试
```

**MEMS 流片方式**：

| 方式 | 说明 | 成本 | 周期 |
|------|------|------|------|
| **MPW（多项目晶圆）** | 多个设计共享一片晶圆 | 低（~$5,000~50,000） | 长（3~6 月） |
| **全定制流片** | 专用掩模和工艺 | 高（~$100,000~500,000+） | 长 |
| **研究型代工** | 大学/研究机构提供标准 MEMS 工艺 | 极低 | 较短 |

**典型 MEMS MPW 服务**：

| 代工服务 | 工艺 | 特点 |
|---------|------|------|
| **SUMMiT（Sandia）** | 5 层多晶硅表面微加工 | 高复杂度结构 |
| **MUMPs（MEMSCAP）** | PolyMUMPs/MetalMUMPs/SoiMUMPs | 经典教学/研究工艺 |
| **PiezoMUMPs（MEMSCAP）** | AlN 压电 + SOI | 压电 MEMS |
| **iMEMS（台积电）** | CMOS + MEMS 集成 | 商业级 |

## 小结

MEMS 技术是微电子领域中**"超越摩尔"路线的典范**，将微型化机械结构与电子电路集成，实现了对物理世界的感知与操控。本章系统介绍了 MEMS 的核心内容：

1. **工艺技术**：体硅微加工（各向异性腐蚀、DRIE）适合制造深腔和高质量块结构；表面微加工（牺牲层技术）适合制造悬空梁和梳状结构；LIGA 工艺适合高深宽比金属结构；键合技术是实现 MEMS 封装和真空腔体的关键。

2. **力学基础**：胡克定律 $\sigma = E\varepsilon$ 是 MEMS 弹性设计的基石；梁的弯曲理论（欧拉-伯努利方程）为悬臂梁、固支梁的刚度和挠度计算提供依据；谐振频率 $f_0 = (1/2\pi)\sqrt{k/m}$ 及其与结构参数的关系是动态设计的基础；残余应力对 MEMS 结构的刚度和稳定性有显著影响。

3. **传感器**：加速度计通过质量块-弹簧系统和差分电容检测实现；陀螺仪基于科里奥利效应，驱动模态和检测模态的设计是关键；压力传感器分为压阻式和电容式，各有优劣；MEMS 麦克风凭借小尺寸和高性能已全面取代传统驻极体麦克风。

4. **执行器**：静电执行器（平行板有 Pull-in 限制，梳状无 Pull-in）功耗极低但需高压驱动；压电执行器驱动力大、响应快；热执行器驱动力最大但响应慢、功耗高。执行器的选择需综合考虑力/位移/速度/功耗的需求。

5. **RF MEMS**：MEMS 开关在插入损耗、隔离度和线性度上远优于固态开关，但开关速度和可靠性仍是瓶颈；MEMS 可变电容、高 Q 电感和谐振器为可重构射频前端提供了新途径。

6. **谐振器**：MEMS 谐振器利用硅的高 Q 机械谐振特性替代石英晶体，通过温度补偿（掺杂、SiO₂、PLL）实现高稳定性，其可编程性、小尺寸和抗冲击特性使其在时钟应用中快速普及。

7. **封装**：MEMS 封装需保护可动结构、维持真空、实现气密性并提供环境交互通道；晶圆级封装（硅帽键合）是主流方案；吸气剂技术维持长期真空。

8. **设计流程**：从系统级等效电路建模，到器件级有限元仿真（FEM），再到工艺级仿真和版图设计，MEMS 设计是多物理场、多尺度的协同优化过程。

MEMS 技术的本质是**机械学与电子学的微型化融合**。随着 5G/6G 射频前端、自动驾驶惯性导航、AR/VR 微显示、BioMEMS 即时诊断等应用的蓬勃发展，MEMS 将继续是微电子领域最具活力和增长潜力的方向之一。

进一步学习建议：

- **经典教材**：Senturia《Microsystem Design》、Madou《Fundamentals of Microfabrication》、Baglio《MEMS: Advanced Introduction》
- **进阶主题**：压电 MEMS、MEMS 滤波器、能量收集器、NEMS（纳机电系统）
- **实践**：使用 CoventorWare/COMSOL 设计一个电容式加速度计或梳状驱动谐振器，从力学仿真到等效电路建模，再到版图设计
