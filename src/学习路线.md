# 学习路线

这是一本“最小公共核心 + 方向主线 + 进阶选修”的自学教程。**章节编号是稳定标识，不代表阅读顺序；应以本页列出的顺序和每章的必需先修为准。**

每章先修分为两类：

- **必需**：不理解就无法掌握本章核心内容，应先完成。
- **推荐**：用于建立直觉、补充应用或继续深入，可按目标选读。

## 9. 阅读建议

1. 先确认目标岗位或项目，再选择一条路线，不同时展开多条进阶分支。
2. 每章先核对“必需先修”；推荐先修不理解时，不必停止主线。
3. 第一遍掌握模型、适用条件和基本计算，第二遍再补推导与高级专题。
4. 自测题答不上来时回到对应小节；练习或仿真失败时保留日志和调参记录。
5. 完成一个可自检的检查点后，再进入下一层或切换方向。
