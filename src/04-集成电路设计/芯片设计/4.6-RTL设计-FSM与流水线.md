## 1. FSM 的 RTL 描述

### 1.1 状态编码

```verilog
// 二进制编码（面积小）
localparam IDLE  = 2'b00;
localparam READ  = 2'b01;
localparam WRITE = 2'b10;

// 独热编码（速度高，适合 FPGA）
localparam IDLE  = 3'b001;
localparam READ  = 3'b010;
localparam WRITE = 3'b100;
```

### 1.2 三段式 FSM

三段式 FSM 将状态寄存器、次态逻辑和输出逻辑分离，代码清晰、易于维护：

```verilog
// 第一段：状态寄存器
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        state <= IDLE;
    else
        state <= next_state;
end

// 第二段：次态逻辑（组合逻辑）
always @(*) begin
    case (state)
        IDLE:  next_state = start ? READ : IDLE;
        READ:  next_state = done ? WRITE : READ;
        WRITE: next_state = done ? IDLE : WRITE;
        default: next_state = IDLE;
    endcase
end

// 第三段：输出逻辑（时序逻辑，无毛刺）
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        data_out <= 1'b0;
        valid    <= 1'b0;
    end else begin
        case (next_state)
            READ:  data_out <= data_in;
            WRITE: valid <= 1'b1;
            default: begin
                data_out <= 1'b0;
                valid    <= 1'b0;
            end
        endcase
    end
end
```

![FSM状态转移图](images/FSM状态转移图.svg)

### 1.3 两段式 FSM（输出为组合逻辑）

```verilog
// 第一段：状态寄存器
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) state <= IDLE;
    else        state <= next_state;
end

// 第二段：次态逻辑 + 输出逻辑（组合逻辑）
always @(*) begin
    next_state = state;
    data_out   = 1'b0;
    valid      = 1'b0;
    case (state)
        IDLE: begin
            if (start) next_state = READ;
        end
        READ: begin
            data_out = data_in;
            if (done) next_state = WRITE;
        end
        WRITE: begin
            valid = 1'b1;
            if (done) next_state = IDLE;
        end
    endcase
end
```

### 1.4 FSM 设计注意事项

| 注意点       | 说明                               |
| ------------ | ---------------------------------- |
| 避免无效状态 | 使用`default` 分支跳转到安全状态 |
| 输出无毛刺   | 使用三段式，输出用时序逻辑         |
| 状态编码选择 | 面积优先用二进制，速度优先用独热码 |
| 综合优化     | 综合工具可自动优化状态编码         |

## 2. 流水线设计

### 2.1 流水线概念

流水线通过在组合逻辑中插入寄存器，将长路径分割为多个短路径，提高系统时钟频率。

![流水线结构图](images/流水线结构图.svg)

### 2.2 三级流水线加法器

```verilog
module pipeline_adder (
    input  clk, rst_n,
    input  [7:0] a, b, c, d,
    output reg [9:0] result
);
    reg [8:0] sum1, sum2;
    reg [7:0] a_reg, b_reg, c_reg, d_reg;

    // 第一级：输入寄存
    always @(posedge clk) begin
        a_reg <= a;
        b_reg <= b;
        c_reg <= c;
        d_reg <= d;
    end

    // 第二级：部分和
    always @(posedge clk) begin
        sum1 <= a_reg + b_reg;
        sum2 <= c_reg + d_reg;
    end

    // 第三级：最终结果
    always @(posedge clk) begin
        result <= sum1 + sum2;
    end
endmodule
```

### 2.3 流水线设计的权衡

| 指标                 | 无流水线         | 3 级流水线     |
| -------------------- | ---------------- | -------------- |
| 关键路径延迟         | 长（组合逻辑深） | 短（每级 1/3） |
| 最大时钟频率         | 低               | 高（约 3 倍）  |
| 延迟（Latency）      | 1 个时钟周期     | 3 个时钟周期   |
| 吞吐量（Throughput） | 1 结果/周期      | 1 结果/周期    |
| 面积                 | 小               | 大（需寄存器） |

## 3. 同步 FIFO 设计

### 3.1 同步 FIFO 结构

![同步FIFO结构图](images/同步FIFO结构图.svg)

### 3.2 核心代码

```verilog
module sync_fifo #(
    parameter DATA_WIDTH = 8,
    parameter DEPTH = 16
)(
    input  clk, rst_n,
    input  wr_en, rd_en,
    input  [DATA_WIDTH-1:0] data_in,
    output reg [DATA_WIDTH-1:0] data_out,
    output full, empty
);
    localparam ADDR_WIDTH = $clog2(DEPTH);

    reg [DATA_WIDTH-1:0] mem [0:DEPTH-1];
    reg [ADDR_WIDTH:0] wr_ptr, rd_ptr;  // 多1位用于判断空满

    // 空满标志（组合逻辑）
    assign full  = (wr_ptr[ADDR_WIDTH] != rd_ptr[ADDR_WIDTH]) && 
                   (wr_ptr[ADDR_WIDTH-1:0] == rd_ptr[ADDR_WIDTH-1:0]);
    assign empty = (wr_ptr == rd_ptr);

    // 读写操作
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            wr_ptr <= 0;
            rd_ptr <= 0;
        end else begin
            if (wr_en && !full) begin
                mem[wr_ptr[ADDR_WIDTH-1:0]] <= data_in;
                wr_ptr <= wr_ptr + 1;
            end
            if (rd_en && !empty) begin
                data_out <= mem[rd_ptr[ADDR_WIDTH-1:0]];
                rd_ptr <= rd_ptr + 1;
            end
        end
    end
endmodule
```

### 3.3 FIFO 深度计算

FIFO 深度取决于读写速率差和最大突发长度：

$$
\text{FIFO Depth} \geq \text{Burst Length} \times \left(1 - \frac{\text{Read Rate}}{\text{Write Rate}}\right)
$$

## 4. 跨时钟域同步

### 4.1 亚稳态问题

当信号跨时钟域传输时，可能发生亚稳态（Metastability），导致逻辑错误。

### 4.2 双级同步器

![跨时钟域同步图](images/跨时钟域同步图.svg)

```verilog
module sync_2stage (
    input  clk_dst, rst_n,
    input  data_in,
    output data_out
);
    reg sync_reg1, sync_reg2;

    always @(posedge clk_dst or negedge rst_n) begin
        if (!rst_n) begin
            sync_reg1 <= 1'b0;
            sync_reg2 <= 1'b0;
        end else begin
            sync_reg1 <= data_in;
            sync_reg2 <= sync_reg1;
        end
    end

    assign data_out = sync_reg2;
endmodule
```

### 4.3 单比特同步方案

| 信号类型   | 同步方案              | 说明             |
| ---------- | --------------------- | ---------------- |
| 电平信号   | 双级同步器            | 2 个触发器打两拍 |
| 脉冲信号   | 边沿检测 + 双级同步器 | 展宽为电平再同步 |
| 快→慢时钟 | 握手机制              | 请求-应答协议    |

### 4.4 多比特同步——异步 FIFO

异步 FIFO 使用格雷码（Gray Code）指针进行跨时钟域同步，确保多比特信号的正确传输：

```verilog
// 二进制转格雷码
assign gray = (binary >> 1) ^ binary;

// 格雷码转二进制
always @(*) begin
    for (int i = 0; i < ADDR_WIDTH; i++)
        binary[i] = ^(gray >> i);
end
```

格雷码相邻值只有一位变化，降低多比特同步的出错概率。

## 5. 同步 / 异步复位

### 5.1 同步复位

仅在时钟沿检查复位信号：

```verilog
always @(posedge clk) begin
    if (!rst_n)  // 仅在时钟沿检查复位
        q <= 1'b0;
    else
        q <= d;
end
```

**优点**：综合后电路简单，无亚稳态问题
**缺点**：复位依赖时钟，无法立即复位

### 5.2 异步复位

立即复位，不依赖时钟：

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)  // 立即复位
        q <= 1'b0;
    else
        q <= d;
end
```

**优点**：复位响应快，无需时钟
**缺点**：复位释放时可能产生亚稳态

### 5.3 异步复位同步释放

结合两者优点：

```verilog
reg rst_n_sync1, rst_n_sync2;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        rst_n_sync1 <= 1'b0;
        rst_n_sync2 <= 1'b0;
    end else begin
        rst_n_sync1 <= 1'b1;
        rst_n_sync2 <= rst_n_sync1;
    end
end

assign rst_n_sync = rst_n_sync2;
```

## 6. 可综合代码风格

### 6.1 可综合与不可综合

| 可综合                        | 不可综合                |
| ----------------------------- | ----------------------- |
| `assign`                    | `initial`             |
| `always @(posedge/negedge)` | `#` 延迟              |
| `always @(*)`               | `wait`                |
| `case / if-else`            | `force / release`     |
| 算术运算                      | `$display / $monitor` |
| 寄存器 / 线网                 | 文件操作                |

### 6.2 设计规范

1. **避免锁存器**：组合逻辑中所有条件分支都要有赋值
2. **避免组合反馈环路**：组合逻辑的输出不能直接反馈到输入
3. **参数化设计**：使用 `parameter` 提高可重用性
4. **模块接口清晰**：功能单一，接口明确
5. **添加注释**：关键逻辑和时序约束

### 6.3 常见陷阱1

```verilog
// 陷阱1：缺少 default 分支 → 产生锁存器
always @(*) begin
    case (sel)
        2'b00: y = a;
        2'b01: y = b;
        // 缺少 2'b10 和 2'b11
    endcase
end

// 陷阱2：同一 always 块混合阻塞和非阻塞赋值
always @(posedge clk) begin
    q1 = d;   // 阻塞
    q2 <= q1; // 非阻塞 → 仿真行为不确定
end

// 陷阱3：敏感列表不完整
always @(a or b) begin  // 漏了 c
    y = a & b & c;
end
```
