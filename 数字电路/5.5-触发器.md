# 5.5 触发器

## 1. 基本 RS 触发器

### 1.1 电路结构

基本 RS 触发器由两个与非门（或两个或非门）交叉耦合构成。

![基本RS触发器逻辑图](images/rs-flipflop-wiki.png)

**用与非门构成的基本 RS 触发器**：
- 输入端：$\overline{R}$（复位端）和 $\overline{S}$（置位端）
- 输出端：$Q$ 和 $\overline{Q}$

### 1.2 逻辑功能

**特性表**（与非门构成）：

| $\overline{R}$ | $\overline{S}$ | $Q$ | $\overline{Q}$ | 功能 |
|---------------|---------------|-----|---------------|------|
| 0 | 0 | 1 | 1 | 禁止（不允许） |
| 0 | 1 | 0 | 1 | 复位（置 0） |
| 1 | 0 | 1 | 0 | 置位（置 1） |
| 1 | 1 | $Q$ | $\overline{Q}$ | 保持 |

**特性方程**：
$$Q_{n+1} = \overline{\overline{R} + \overline{S} \cdot Q_n} = S + \overline{R} \cdot Q_n$$
约束条件：$\overline{R} + \overline{S} = 1$（即 $\overline{R} \cdot \overline{S} = 0$，不允许 $\overline{R}$ 和 $\overline{S}$ 同时为 0）

### 1.3 状态转换图

状态转换图用圆圈表示状态，箭头表示状态转换方向，转换条件标注在箭头旁。

## 2. 同步触发器（电平触发）

### 2.1 同步 RS 触发器

在基本 RS 触发器基础上增加时钟控制端 CP（Clock Pulse）。

**特性方程**：
$$Q_{n+1} = S + \overline{R} \cdot Q_n \quad (\text{CP}=1 \text{ 时有效})$$
约束条件：$R \cdot S = 0$

### 2.2 同步 D 触发器

在同步 RS 触发器基础上增加一个反相器，消除禁止状态。

$$Q_{n+1} = D \quad (\text{CP}=1 \text{ 时有效})$$

### 2.3 同步触发器的空翻问题

电平触发方式在 CP 高电平期间，触发器状态可能发生多次翻转，称为"空翻"。空翻限制了触发器的应用，因此发展出主从触发器和边沿触发器。

## 3. 主从触发器（脉冲触发）

### 3.1 主从 RS 触发器

由两个同步 RS 触发器（主触发器和从触发器）级联构成。

**工作原理**：
- CP=1 期间：主触发器接收输入信号，从触发器被封锁（保持原状态）
- CP 下降沿：从触发器接收主触发器的状态，主触发器被封锁

**一次变化问题**：在 CP=1 期间，主触发器只响应输入信号的第一次变化，随后输入的变化不再影响主触发器，称为"一次变化"问题。

### 3.2 主从 JK 触发器

主从 JK 触发器解决了 RS 触发器的约束问题。

**特性方程**：
$$Q_{n+1} = J\overline{Q_n} + \overline{K}Q_n$$

## 4. 边沿触发器

### 4.1 边沿 JK 触发器

边沿触发器只在时钟信号的上升沿或下降沿时刻接收输入信号并改变状态，从根本上解决了空翻问题。

**特性方程**：
$$Q_{n+1} = J\overline{Q_n} + \overline{K}Q_n \quad (\text{CP 上升沿或下降沿触发})$$

### 4.2 边沿 D 触发器

边沿 D 触发器是最常用的边沿触发器之一，常用于数据寄存和移位寄存器。

**特性方程**：
$$Q_{n+1} = D \quad (\text{CP 上升沿触发})$$

### 4.3 边沿 T 触发器

T 触发器（Toggle Flip-Flop）具有翻转功能。

**特性方程**：
$$Q_{n+1} = T \oplus Q_n = T\overline{Q_n} + \overline{T}Q_n$$

当 $T=1$ 时，每来一个时钟脉冲，触发器翻转一次（计数状态）。
当 $T=0$ 时，触发器保持原状态。

## 5. 常用触发器类型

### 5.1 SR 触发器

**特性方程**：
$$Q_{n+1} = S + \overline{R} \cdot Q_n, \quad R \cdot S = 0$$

### 5.2 JK 触发器

**特性方程**：
$$Q_{n+1} = J\overline{Q_n} + \overline{K}Q_n$$

**功能表**：

| J | K | $Q_{n+1}$ | 功能 |
|---|---|-----------|------|
| 0 | 0 | $Q_n$ | 保持 |
| 0 | 1 | 0 | 复位 |
| 1 | 0 | 1 | 置位 |
| 1 | 1 | $\overline{Q_n}$ | 翻转 |

### 5.3 D 触发器

**特性方程**：
$$Q_{n+1} = D$$

**功能表**：

| D | $Q_{n+1}$ |
|---|-----------|
| 0 | 0 |
| 1 | 1 |

### 5.4 T 触发器

**特性方程**：
$$Q_{n+1} = T \oplus Q_n$$

**功能表**：

| T | $Q_{n+1}$ |
|---|-----------|
| 0 | $Q_n$ |
| 1 | $\overline{Q_n}$ |

### 5.5 特性方程与状态转换图

**JK 触发器状态转换图**：

```
        J=0,K=X
  ┌───────────────┐
  ▼               │
  0 ────────→ 1
  │ J=1,K=X    J=X,K=0
  │               │
  └───────────────┘
  J=X,K=1
```

## 6. 各类触发器相互转换

### 6.1 JK 触发器转 D 触发器

比较特性方程：
$$Q_{n+1}(\text{JK}) = J\overline{Q_n} + \overline{K}Q_n$$
$$Q_{n+1}(\text{D}) = D = D(Q_n + \overline{Q_n}) = DQ_n + D\overline{Q_n}$$

令 $J = D$，$K = \overline{D}$，即可实现。

### 6.2 D 触发器转 JK 触发器

在 D 触发器输入端添加转换逻辑：
$$D = J\overline{Q_n} + \overline{K}Q_n$$

### 6.3 D 触发器转 T 触发器

$$D = T \oplus Q_n$$

### 6.4 JK 触发器转 T 触发器

令 $J = K = T$，则：
$$Q_{n+1} = T\overline{Q_n} + \overline{T}Q_n = T \oplus Q_n$$

## 7. 动态特性

### 7.1 建立时间（Setup Time, $t_{su}$）

在时钟有效沿到来之前，输入数据必须保持稳定的最小时间。

### 7.2 保持时间（Hold Time, $t_h$）

在时钟有效沿到来之后，输入数据必须保持稳定的最小时间。

### 7.3 传输延迟

- $t_{PLH}$：从时钟有效沿到输出从低到高的延迟
- $t_{PHL}$：从时钟有效沿到输出从高到低的延迟

### 7.4 最高时钟频率

$$f_{max} = \frac{1}{t_{su} + t_{pd} + t_{margin}}$$

其中 $t_{pd}$ 为触发器内部传输延迟，$t_{margin}$ 为设计裕量。

### 7.5 触发器的主要应用

- **寄存器**：多个D触发器并联，在时钟上升沿同时锁存数据
- **计数器**：多个T触发器或JK触发器级联，实现二进制计数
- **分频器**：T触发器每来一个时钟翻转一次，实现二分频
- **状态寄存器**：在有限状态机中存储当前状态
- **数据同步器**：双级触发器消除亚稳态（使用两个D触发器级联）
