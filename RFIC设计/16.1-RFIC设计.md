# 16.1 RFIC设计

## 1. 引言

射频集成电路（Radio-Frequency Integrated Circuit, RFIC）是无线通信系统的核心硬件基石。从手机、Wi-Fi 路由器、蓝牙耳机到雷达、卫星通信、5G/6G 基站，几乎所有无线连接的背后都离不开 RFIC 的支撑。与基带数字电路和低频模拟电路相比，射频电路工作在数百 MHz 至数百 GHz 的频段，面临着**寄生效应显著、阻抗匹配严苛、噪声与线性度矛盾、功耗与效率折中**等多重独特挑战。

随着 CMOS 工艺特征尺寸不断缩小，晶体管的特征频率 $f_T$ 和最大振荡频率 $f_{max}$ 已突破数百 GHz，使得在硅基工艺上集成完整的射频收发机成为可能。然而，低电源电压、低击穿电压、有源器件噪声性能差、衬底损耗大等问题，又对 RFIC 设计者提出了新的要求。RFIC 设计本质上是**电路拓扑、电磁场、噪声与线性度、版图与封装**的多维度协同优化问题。

本章将系统介绍 RFIC 设计的核心概念、关键模块和设计方法，涵盖接收机与发射机架构、低噪声放大器（LNA）、混频器、射频功率放大器（PA）、频率综合器以及版图与设计流程等内容，为读者建立完整的 RFIC 设计知识体系。

## 2. RFIC设计概述

### 2.1 RFIC在无线通信系统中的地位

一个典型无线通信系统的硬件链路可划分为**射频前端**、**模拟基带**、**数据转换器（ADC/DAC）**、**数字基带**四个部分：

```
天线 ──→ [RF前端] ──→ [模拟基带] ──→ [ADC] ──→ [数字基带/DSP]
         LNA/混频器     滤波/VGA               
         ↑ 发射路径 ↓
天线 ←── [RF前端] ←── [模拟基带] ←── [DAC] ←── [数字基带/DSP]
         PA/上变频      滤波/VGA
```

RFIC 承担射频前端及部分模拟基带功能，是连接电磁波与数字世界的关键桥梁。其重要性体现在：

| 维度 | 说明 |
|------|------|
| **性能瓶颈** | 接收机灵敏度、发射机效率、频谱纯度等系统级指标主要由 RFIC 决定 |
| **功耗占比** | 移动终端中射频前端功耗可达总功耗的 20%~50%（含 PA） |
| **面积/成本** | 射频无源器件（电感、变压器）面积大，是芯片成本的重要组成 |
| **集成度驱动** | CMOS RFIC 推动了"单芯片无线电"（Single-Chip Radio）的实现 |

### 2.2 RFIC设计流程与挑战

RFIC 设计流程一般分为规格定义 → 系统架构 → 电路设计 → 仿真验证 → 版图 → 后仿真 → 流片 → 测试等阶段：

```
应用规格 → 链路预算 → 架构选型 → 模块划分 → 原理图设计
                                                     ↓
测试 ←─ 流片 ←─ 后仿真(EM+寄生) ←─ 版图 ←─ 前仿真 ←─┘
```

RFIC 设计面临的独特挑战：

| 挑战 | 描述 | 应对策略 |
|------|------|----------|
| **射频频率高** | GHz 级频率下寄生电容/电感显著，传输线效应不可忽略 | EM 仿真、共面波导/微带线建模 |
| **阻抗匹配** | 各级间需 50Ω 或共轭匹配以最大化功率传输 | Smith 圆图、L/π/T 网络 |
| **噪声** | 接收机灵敏度受 LNA 噪声系数限制 | 噪声匹配、低噪声拓扑 |
| **线性度** | 强干扰下产生交调失真，阻塞有用信号 | 线性化技术、高线性度拓扑 |
| **功耗** | 移动设备要求低功耗，PA 要求高效率 | 亚阈值设计、开关型 PA |
| **工艺限制** | CMOS 低电压、低击穿、衬底损耗 | cascode、变压器合成、SOI/GaAs |
| **寄生效应** | 互连、衬底耦合、键合线寄生严重影响性能 | 仔细版图、屏蔽、EM 仿真 |
| **测量困难** | GHz 频段下探针、校准、夹具引入误差 | SOLT/TRL 校准、片上测试 |

### 2.3 射频收发机架构概览

一个完整的射频收发机由接收机（RX）、发射机（TX）和频率综合器（LO）三部分组成：

```
        ┌───────────── 接收链路 (RX) ─────────────┐
天线 ──→ BAW/SAW滤波 ──→ LNA ──→ 下变频混频 ──→ 基带滤波/VGA ──→ ADC
                                                    ↑
                                    LO（频率综合器）
                                                    ↓
        ┌───────────── 发射链路 (TX) ─────────────┐
DAC ──→ 基带滤波/VGA ──→ 上变频混频 ──→ PA ──→ 双工器 ──→ 天线
```

后续章节将分别详细讨论接收机、发射机以及关键模块的设计。

## 3. RF接收机架构

接收机的核心任务是从空间中微弱的有用射频信号中**放大、下变频并过滤**出基带信号，同时抑制镜像、阻塞和噪声。不同架构在复杂度、集成度和性能之间做出不同折中。

### 3.1 超外差接收机（Superheterodyne）

超外差（Super-Heterodyne）架构由 Armstrong 于 1918 年提出，至今仍是高性能接收机的主流方案。其核心思想是**两级下变频**：先将射频信号变换到固定中频（IF），再变换到基带。

```
天线 → RF滤波 → LNA → RF滤波 → 混频器₁ → IF滤波 → IF放大 → 混频器₂ → 基带
                              ↑                              ↑
                            LO₁=RF-IF                       LO₂=IF
```

#### 3.1.1 镜像频率问题

混频器是频率无关的乘法器，对位于 $f_{LO} \pm f_{IF}$ 的输入信号都会下变频到同一中频 $f_{IF}$。其中与有用信号关于 LO 对称的频率称为**镜像频率** $f_{IM}$：

$$
f_{RF} = f_{LO} + f_{IF} \quad \Rightarrow \quad f_{IM} = f_{LO} - f_{IF} = f_{RF} - 2f_{IF}
$$

镜像干扰必须由 RF 前端的**镜像抑制滤波器（IR Filter）** 在混频前滤除，否则将与有用信号叠加而无法分离。镜像抑制要求决定了 IR Filter 的 Q 值与插入损耗。

**镜像抑制比（IRR）**：

$$
IRR = 10\log\left[1 + \left(\frac{Q \cdot 2f_{IF}}{f_{RF}}\right)^2\right] \text{ (dB)}
$$

#### 3.1.2 中频（IF）选择

中频选择是超外差设计的核心折中：

| IF 选择 | 镜像距离 | IR 滤波器 | 信道选择性 | 说明 |
|---------|---------|-----------|------------|------|
| **高 IF**（>RF/2） | 远 | 容易实现 | 差（需高 Q SAW） | 镜像易抑制，但信道滤波难 |
| **低 IF**（~几 MHz） | 近 | 难（需高 Q RF 滤波器） | 好（可用低频滤波器） | 信道滤波容易，镜像抑制难 |
| **多级 IF** | — | 折中 | 折中 | 经典方案，但成本高 |

工程上常采用**多级变频**：第一高中频便于镜像抑制，第二低中频便于信道选择。例如某 GPS 接收机：RF = 1575.42 MHz → IF1 = 175.42 MHz → IF2 = 4.092 MHz。

### 3.2 零中频接收机（Zero-IF / Direct Conversion）

零中频（直接变频）架构将 RF 信号一次性下变频到基带，本地振荡频率等于载波频率：

```
天线 → RF滤波 → LNA → I/Q混频器 → 低通滤波 → VGA → ADC
                       ↑
                   LO = fRF（正交）
```

为分离频谱重叠的正负频率分量，需采用**正交下变频**（I/Q 解调）：

$$
I(t) = LPF\left[r(t)\cos(\omega_{LO}t)\right], \quad Q(t) = LPF\left[-r(t)\sin(\omega_{LO}t)\right]
$$

#### 3.2.1 优势

| 优势 | 说明 |
|------|------|
| **无镜像问题** | 镜像即自身，I/Q 解调可分离正负频率 |
| **集成度高** | 信道滤波由低频低通滤波器实现，易片上集成 |
| **简单灵活** | 仅需一次变频，频段切换灵活 |
| **低成本** | 省去片外 SAW/中频器件 |

#### 3.2.2 挑战

| 挑战 | 机理 | 影响 | 缓解方法 |
|------|------|------|---------|
| **直流偏移（DC Offset）** | LO 自混频、强干扰自混频产生直流量 | 阻塞 VGA/ADC，恶化信噪比 | AC 耦合、直流校准、谐波混频 |
| **I/Q 失配** | I/Q 两路增益/相位不匹配 | 镜像抑制恶化，EVM 退化 | 校准、几何匹配、数字补偿 |
| **闪烁噪声（1/f）** | MOS 器件 1/f 噪声下变频到基带 | 灵敏度下降（尤其窄带信号） | 大器件、差分结构、谐波混频 |
| **偶阶失真** | 二阶非线性使干扰自混频到基带 | 产生基带干扰，恶化信噪比 | 差分电路、IP2 校准 |
| **LO 泄漏** | LO 通过衬底/寄生耦合到天线口 | 自干扰、DC 偏移 | 屏蔽、布局隔离、LO ≤ RF |

**I/Q 失配对镜像抑制的影响**：

设 I/Q 增益失配为 $\epsilon$，相位失配为 $\Delta\phi$，则镜像抑制比为：

$$
IRR = 10\log\left(\frac{(2+\epsilon)^2 + (\Delta\phi)^2}{\epsilon^2 + (\Delta\phi)^2}\right) \approx 10\log\left(\frac{4}{\epsilon^2 + (\Delta\phi)^2}\right) \text{ (dB)}
$$

例如要达到 40 dB IRR，要求 $\epsilon < 1\%$ 且 $\Delta\phi < 1^\circ$，对模拟电路而言相当苛刻。

### 3.3 低中频接收机（Low-IF）

低中频架构将中频选择在**信道带宽量级**（数百 kHz ~ 数 MHz），介于超外差与零中频之间：

```
天线 → RF滤波 → LNA → I/Q混频器 → 复数带通滤波 → ADC → 数字下变频
                       ↑
                   LO = RF ± IF
```

#### 3.3.1 折中方案

- **优点**：避开 1/f 噪声与 DC 偏移问题；可保留超外差的灵活性；信号仍位于低频，便于数字处理
- **缺点**：镜像位于邻近信道，需要复数（多相）滤波器实现镜像抑制；对 I/Q 失配依然敏感

#### 3.3.2 镜像抑制要求

低中频下镜像信号可能比有用信号强 50 dB 以上（邻近信道），需通过**复数带通滤波**和**I/Q 校准**实现 60~80 dB 镜像抑制：

- **复数滤波**：通过多相（Polyphase）滤波器对 I/Q 信号进行复数域滤波，选择性地抑制镜像
- **数字校准**：在数字域估计并补偿 I/Q 失配，可达到 >60 dB IRR

### 3.4 接收机架构对比

| 指标 | 超外差 | 零中频 | 低中频 |
|------|--------|--------|--------|
| **变频级数** | 多级 | 单级 | 单级 |
| **镜像抑制** | RF 滤波器 | I/Q 解调（自镜像） | 复数滤波 + I/Q |
| **中频处理** | 片外 SAW/晶体滤波 | 片上低通 | 片上复数带通/数字 |
| **DC 偏移** | 无 | 严重 | 轻微 |
| **1/f 噪声** | 无影响 | 严重 | 轻微 |
| **I/Q 失配敏感性** | 中 | 高 | 高 |
| **集成度** | 低 | 高 | 高 |
| **成本/面积** | 高 | 低 | 低 |
| **典型应用** | 高性能电台、雷达 | 手机、Wi-Fi | 蓝牙、ZigBee、FM |

工程上常根据应用场景、灵敏度要求、成本约束综合选择架构。

## 4. 低噪声放大器（LNA）设计

LNA 是接收机的第一级有源电路，其噪声系数直接决定整机的灵敏度。LNA 的核心设计矛盾是：**输入匹配（50Ω） ↔ 噪声匹配 ↔ 功耗 ↔ 增益 ↔ 线性度**。

### 4.1 LNA设计指标

| 指标 | 定义 | 典型值 |
|------|------|--------|
| **噪声系数 NF** | 输入信噪比与输出信噪比之比 | 1.5~3 dB |
| **功率增益 $G_P$** | 输出与输入功率比 | 12~20 dB |
| **输入反射 $S_{11}$** | 输入端反射系数 | < -10 dB |
| **IIP3** | 三阶交调输入截点 | -10 ~ +5 dBm |
| **IIP2** | 二阶交调输入截点 | +20 ~ +50 dBm |
| **1dB 压缩点 $P_{1dB}$** | 增益下降 1dB 时的输入功率 | -20 ~ -5 dBm |
| **功耗** | 静态电流 × 电源电压 | 5~15 mW |
| **反向隔离 $S_{12}$** | LO 泄漏到天线的指标 | < -30 dB |
| **稳定性 $K$ 因子** | Rollet 稳定因子 | > 1 |

### 4.2 噪声系数理论

#### 4.2.1 Friis 级联噪声公式

对于多级级联系统，总噪声系数由 Friis 公式给出：

$$
F_{total} = F_1 + \frac{F_2 - 1}{G_1} + \frac{F_3 - 1}{G_1 G_2} + \cdots + \frac{F_n - 1}{\prod_{i=1}^{n-1} G_i}
$$

**结论**：第一级的噪声系数 $F_1$ 起主导作用，且其增益 $G_1$ 越大，后续各级噪声贡献越小。这就是 LNA 必须低噪声、足够增益的根本原因。

**例**：LNA NF=2 dB，G=15 dB；后级混频器 NF=10 dB。整链路 NF：

$$F = 10^{0.2} + \frac{10^{1}-1}{10^{1.5}} \approx 1.585 + 0.316 \approx 1.90 \Rightarrow NF \approx 2.79\text{ dB}$$

#### 4.2.2 最小噪声系数

MOS 管的两端口噪声参数（经典模型）：

$$
F_{min} = 1 + \frac{2}{\sqrt{5}}\frac{\omega}{\omega_T}\frac{\gamma}{\alpha}\sqrt{\delta\left(1 - |c|^2\right)}
$$

其中：
- $\omega_T = g_m / C_{gs}$ 为特征角频率
- $\gamma$ 为沟道热噪声系数（长沟道 2/3，短沟道 1~2）
- $\delta$ 为栅极感应噪声系数（~4/3）
- $c$ 为沟道噪声与栅极噪声相关系数
- $\alpha = g_m / g_{d0}$

最优源阻抗为：

$$
Y_{opt} = g_{opt} + j b_{opt}, \quad g_{opt} = \alpha\omega C_{gs}\sqrt{\frac{\delta}{5\gamma}(1-|c|^2)}
$$

任意源阻抗下的噪声系数：

$$
F = F_{min} + \frac{R_n}{G_s}\left|Y_s - Y_{opt}\right|^2
$$

其中 $R_n$ 为等效噪声电阻，反映对失配的敏感程度。

#### 4.2.3 噪声匹配与功率匹配的矛盾

- **功率匹配**：$Y_s = Y_{in}^*$，最大化功率传输
- **噪声匹配**：$Y_s = Y_{opt}$，最小化噪声系数

两者一般不重合，需要在拓扑上巧巧设计使其接近，或在指标上折中。

### 4.3 共源 LNA（源极电感负反馈）

**共源 LNA + 源极电感负反馈**是 RF CMOS LNA 最经典的拓扑，可在不消耗电压裕度的同时实现**实部输入阻抗**，从而同时达到功率匹配与噪声匹配。

#### 4.3.1 输入阻抗匹配

电路结构：输入管 $M_1$ 栅极接输入信号，栅极串联电感 $L_g$，源极接电感 $L_s$，漏极接谐振负载。

小信号输入阻抗（忽略 $C_{gd}$、$g_{ds}$）：

$$
Z_{in}(\omega) = j\omega L_g + j\omega L_s + \frac{1}{j\omega C_{gs}} + \omega_T L_s
$$

在谐振频率 $\omega_0$ 下，感抗与容抗抵消：

$$
\omega_0 = \frac{1}{\sqrt{(L_g + L_s)C_{gs}}}
$$

谐振时输入阻抗呈纯阻性：

$$
Z_{in}(\omega_0) = \omega_T L_s \approx \frac{g_m}{C_{gs}} L_s
$$

**设计方程**：令 $Z_{in} = R_s = 50\Omega$，得：

$$
L_s = \frac{R_s}{\omega_T}, \quad L_g = \frac{1}{\omega_0^2 C_{gs}} - L_s
$$

#### 4.3.2 噪声分析

在源极电感负反馈结构下，最优噪声匹配阻抗 $Z_{opt}$ 的实部恰好接近 $R_s$，可通过尺寸优化（即调整 $C_{gs}$ 和 $g_m$）使两者重合，达到**功率匹配 ≈ 噪声匹配**。

经典最优噪声系数（忽略栅极噪声）：

$$
NF_{min} \approx 1 + \frac{2}{\sqrt{5}}\frac{\omega_0}{\omega_T}\frac{\gamma}{\alpha}
$$

**功耗约束下的最优设计**（Lee 论证）：在给定功耗 $P_D$ 下，存在最优器件宽度 $W_{opt}$：

$$
W_{opt} \approx \frac{3}{2}\frac{1}{\omega_0 L C_{ox} R_s Q_{opt}}, \quad Q_{opt} \approx 3.5 \sim 5
$$

#### 4.3.3 优缺点

| 优点 | 缺点 |
|------|------|
| 同时实现功率与噪声匹配 | 需片上电感，面积大 |
| 输入阻抗实部可调 | 源极电感 Q 值影响 NF |
| 增益较高 | 单级增益受 cascode 限制 |
| 适合窄带应用 | 宽带匹配困难 |

### 4.4 Cascode LNA

在共源 LNA 的基础上增加共栅管 $M_2$，构成 **Cascode 结构**：

```
VDD ── 谐振负载 ── 漏极输出
                |
                M2（共栅）
                |
                M1（共源）── 源极电感 Ls
                |
               GND
输入 ── Lg ──→ M1栅极
```

#### 4.4.1 优势

| 优势 | 原理 |
|------|------|
| **增益提升** | $M_2$ 屏蔽 $M_1$ 的 Miller 效应，$C_{gd}$ 等效输入电容变小，提高增益带宽积 |
| **隔离度改善** | $M_2$ 隔离输出与输入，减小 LO 反向泄漏到天线，提高 $S_{12}$ |
| **稳定性提升** | 减小输入输出耦合，使 $K>1$ 更易满足 |
| **线性度改善** | $M_1$ 漏极电压摆幅小，减小 $M_1$ 的非线性 |

#### 4.4.2 设计注意

- $M_2$ 的尺寸约为 $M_1$ 的 0.5~1 倍，降低 $M_2$ 寄生电容对增益的影响
- $M_2$ 栅极需良好去耦（AC 地），否则引入增益损失
- Cascode 增加了一个 $V_{DS,sat}$ 电压裕度，对低压工艺（≤1.2V）不利

### 4.5 共栅 LNA

共栅 LNA 直接利用共栅管提供宽带实部输入阻抗，无需电感负反馈：

```
VDD ── 负载 ── 漏极输出
             |
             M1（共栅）
             |
       输入 ─┘（源极）
       偏置
```

#### 4.5.1 输入阻抗

$$
Z_{in} \approx \frac{1}{g_m + g_{mb}} \parallel \frac{1}{j\omega C_{gs}}
$$

若令 $g_m = 1/R_s = 20\text{ mS}$，则 $Z_{in} = 50\Omega$，实现宽带匹配。

#### 4.5.2 噪声性能

共栅 LNA 噪声系数（无 $g_{mb}$、忽略 $r_o$）：

$$
F \approx 1 + \frac{\gamma}{\alpha}\frac{1}{g_m R_s} = 1 + \frac{\gamma}{\alpha}
$$

长沟道下 $\gamma=2/3, \alpha=1$，得 $F \approx 1.67$（即 NF ≈ 2.2 dB）。比共源 LNA 略差，但**与频率无关**，适合超宽带应用。

#### 4.5.3 改进：电流复用技术

为改善 NF，可采用**电流复用（CG-CS）**结构：CG 提供匹配，CS 提供额外增益且不消耗额外电流；也可加 $g_m$-boosting（在栅极施加反向输入）将 NF 降至 1.5~1.8 dB。

### 4.6 LNA线性度分析

#### 4.6.1 IIP3（三阶交调）

LNA 非线性用幂级数展开：

$$
y(t) = a_1 x(t) + a_2 x^2(t) + a_3 x^3(t) + \cdots
$$

输入两等幅信号 $x(t) = A\cos(\omega_1 t) + A\cos(\omega_2 t)$，输出包含三阶交调分量 $\omega_{2\omega_1-\omega_2}$、$\omega_{2\omega_2-\omega_1}$：

$$
\text{IM3 功率} = \frac{9}{4}a_3^2 A^6, \quad \text{基波功率} = a_1^2 A^2
$$

令 IM3 = 基波，解得**输入截点 IIP3**：

$$
A_{IIP3} = \sqrt{\frac{4}{3}\left|\frac{a_1}{a_3}\right|}, \quad P_{IIP3} = \frac{A_{IIP3}^2}{2R_s}
$$

用 dBm 表示并联系输入功率 $P_{in}$ 与 IM3 功率：

$$
P_{IM3} = 3P_{in} - 2P_{IIP3}
$$

**级联 IIP3**：

$$
\frac{1}{P_{IIP3,total}^{2/3}} = \frac{1}{P_{IIP3,1}^{2/3}} + \frac{G_1^{2/3}}{P_{IIP3,2}^{2/3}} + \cdots
$$

#### 4.6.2 1dB 压缩点

增益压缩描述大信号下放大器线性范围：

$$
P_{1dB} \approx P_{IIP3} - 9.6\text{ dB}
$$

即两者通常相差约 10 dB，作为快速估算。

### 4.7 设计实例（5GHz WLAN LNA）

**设计规格**：

| 参数 | 目标 |
|------|------|
| 频率 | 5.15~5.85 GHz |
| NF | < 2.5 dB |
| 增益 | > 15 dB |
| $S_{11}$ | < -15 dB |
| IIP3 | > -5 dBm |
| 功耗 | < 8 mW（1.2V，6.7mA） |
| 工艺 | 65nm CMOS |

**设计要点**：

1. **拓扑**：Cascode 源极电感负反馈
2. **器件尺寸**：$W/L = 80\mu m/60nm$，$g_m \approx 20\text{ mS}$
3. **电感**：$L_s \approx 0.5\text{ nH}$（满足 $Z_{in}=50\Omega$），$L_g \approx 1.8\text{ nH}$
4. **负载**：$LC$ 谐振于 5.5 GHz，提供 8 dB 增益
5. **cascode 管**：尺寸 0.5×主管，栅极 AC 接地
6. **版图**：共中心对称布局，电感间距 > 3 倍线宽

**仿真结果**：NF=2.2 dB，Gain=16 dB，$S_{11}$=-18 dB，IIP3=+1 dBm，功耗=7.8 mW，满足规格。

## 5. 混频器（Mixer）设计

混频器是频率变换的核心模块，利用非线性或开关特性实现**两个信号的相乘**，从而完成上变频或下变频：

$$
v_{out}(t) = v_{RF}(t)\cdot v_{LO}(t) = \cos(\omega_{RF}t)\cos(\omega_{LO}t) = \frac{1}{2}\left[\cos(\omega_{RF}-\omega_{LO})t + \cos(\omega_{RF}+\omega_{LO})t\right]
$$

下变频取差频（$\omega_{IF}=\omega_{RF}-\omega_{LO}$），上变频取和频。

### 5.1 混频器指标

| 指标 | 定义 | 典型值 |
|------|------|--------|
| **转换增益 CG** | IF 输出与 RF 输入功率（或电压）之比 | 有源：5~15 dB；无源：-7~-4 dB |
| **噪声系数 NF**（SSB/DSB） | 单边带/双边带噪声系数 | SSB：10~15 dB |
| **IIP3** | 三阶交调截点 | -5 ~ +10 dBm |
| **IIP2** | 二阶交调截点 | +30 ~ +60 dBm |
| **端口隔离度** | LO-RF、LO-IF、RF-IF 隔离 | > 30 dB |
| **LO 泄漏** | LO 信号泄漏到 RF 端口 | < -50 dBm |
| **1dB 压缩点** | 线性度指标 | -10 ~ 0 dBm |
| **功耗** | 静态功耗 | 2~10 mW |

### 5.2 有源混频器

#### 5.2.1 单平衡吉尔伯特混频器

由跨导级 $M_1$（将 RF 电压转换为电流）和开关对 $M_2$-$M_3$（受 LO 控制切换电流路径）组成：

```
         VDD
          |
       IF+  IF-
        |   |
       M3   M2
        |   |
        └┬──┬┘
         M1（跨导）
          |
        RF输入
```

- **优点**：可获得转换增益；隔离 LO 与 RF 端口
- **缺点**：LO-RF 隔离有限；存在 LO 到 IF 的馈通

#### 5.2.2 双平衡吉尔伯特混频器

将 RF 也用差分对 $M_{1a}$-$M_{1b}$ 处理，输出差分：

```
        VDD
         |
      IF+    IF-
       |      |
      M4 M3 M2 M5
       \ |   | /
        \ \ / /
         M1a M1b
          \   /
          RF差分
```

- **优点**：LO-IF、RF-IF 隔离更好；抑制 LO 偶阶分量；偶阶失真改善
- **缺点**：需要差分 LO 与 RF；功耗更大；噪声略高

#### 5.2.3 转换增益分析

设 LO 为理想方波（占空比 50%），其傅里叶展开：

$$
s(t) = \frac{4}{\pi}\sum_{n=1,3,5,\ldots}^{\infty}\frac{1}{n}\sin(n\omega_{LO}t)
$$

跨导级输出电流 $i_{RF}(t) = g_m v_{RF}(t)$ 被开关函数 $s(t)$ 调制，取基频成分：

$$
i_{IF}(t) = \frac{2}{\pi}g_m v_{RF}(t)
$$

转换电压增益（设负载电阻 $R_L$）：

$$
CG_V = \frac{2}{\pi}g_m R_L
$$

#### 5.2.4 噪声分析

吉尔伯特混频器的主要噪声来源：

| 噪声源 | 贡献 | 优化 |
|--------|------|------|
| 跨导管 $M_1$ 热噪声 | 直接被放大到输出 | 增大 $g_m$ |
| 开关对热噪声 | 1/f 噪声上变频到 IF | 大器件、改善 LO 波形 |
| 1/f 噪声（关键） | 直接位于基带，影响灵敏度 | 大尺寸开关管、谐波混频 |
| LO 相位噪声 | 转换为 IF 噪声 | 高质量 LO |

**SSB 噪声系数近似**：

$$
NF_{SSB} \approx 10\log\left(1 + \frac{\gamma}{\alpha}\frac{\pi^2}{4}\frac{1}{g_m R_s} + \cdots\right)
$$

### 5.3 无源混频器

无源混频器利用 MOS 管作为开关，无偏置电流，**线性度高、1/f 噪声低**。

#### 5.3.1 二极管环混频器

由 4 只或 8 只二极管组成环形（双平衡）结构，LO 信号驱动二极管导通切换。**优势**：极高带宽（>10 GHz）、高 IIP3（>20 dBm）；**缺点**：转换损耗 6~9 dB，需大 LO 功率（>+7 dBm）。

#### 5.3.2 MOS 无源混频器

由 4 只 MOS 管构成开关环，受 LO 大幅信号驱动工作在开关状态：

```
RF+ ── M1/M2 ── IF+
RF- ── M3/M4 ── IF-
        ↑ LO
```

**优势**：

- **高线性度**：无源工作，IIP3 > +15 dBm
- **低 1/f 噪声**：无偏置电流，1/f 噪声极低，适合零中频接收机
- **宽带**：频率上限仅由开关速度决定

**缺点**：

- 转换损耗 4~8 dB（需后级高增益 VGA 补偿）
- 需要大 LO 摆幅（接近电源电压）
- 端口间隔离依赖于 LO 时钟质量

**改进**：电流模无源混频器（在跨导级与开关之间引入虚拟电压，使跨导工作于电流模式），可显著改善线性度。

### 5.4 混频器线性度

#### 5.4.1 IIP3 分析

混频器的非线性来源：

1. **跨导级非线性**（有源混频器主导）：与 LNA 类似
2. **开关对非线性**：LO 非理想方波导致
3. **负载非线性**：大信号下电阻/电感饱和

有源混频器 IIP3 通常受限于跨导级：

$$
P_{IIP3} \propto \frac{V_{GS}-V_{TH}}{R_s}
$$

#### 5.4.2 偶阶失真（IIP2）

二阶非线性产生 DC 分量与二谐波，在零中频架构中尤为有害。**双平衡结构**本身可提供 40~60 dB IIP2，外加**校准**（数字估计并补偿失配）可达 >80 dBm。

### 5.5 设计实例（下变频混频器）

**规格**：5 GHz RF → 500 MHz IF，CG > 8 dB，NF < 12 dB，IIP3 > 0 dBm，功耗 < 6 mW。

**设计**：双平衡吉尔伯特拓扑；RF 跨导 $g_m = 8\text{ mS}$，$R_L = 1.5\text{ k}\Omega$，预期 CG ≈ $\frac{2}{\pi}\times 8 \times 1.5 \approx 7.6$ dB；开关管尺寸 $W/L = 40\mu m/60nm$；LO 摆幅 600 mVpp。仿真：CG=9.2 dB，NF=11.3 dB，IIP3=+3 dBm，功耗=5.4 mW。

## 6. 射频功率放大器（PA）设计

PA 是发射机的最后一级，将基带上变频后的射频信号放大到天线所需的功率水平。PA 的核心设计矛盾是**效率 ↔ 线性度 ↔ 输出功率**，并受限于晶体管的击穿电压和热性能。

### 6.1 PA设计指标

| 指标 | 定义 | 典型值 |
|------|------|--------|
| **饱和输出功率 $P_{sat}$** | 最大输出功率 | +20 ~ +35 dBm |
| **1dB 压缩点 $P_{1dB}$** | 线性范围标志 | $P_{sat}$ - 3 dB |
| **功率附加效率 PAE** | $(P_{out}-P_{in})/P_{DC}$ | 20%~70% |
| **漏极效率 $\eta_D$** | $P_{out}/P_{DC}$ | 30%~80% |
| **增益** | 输出/输入功率比 | 15~30 dB |
| **ACLR** | 相邻信道泄漏比 | < -45 dBc（WCDMA） |
| **EVM** | 误差向量幅度 | < 5%（OFDM） |
| **稳定性 $K$** | 无条件稳定 | > 1 |

### 6.2 PA分类

按导通角 $\theta$ 与工作状态分类：

| 类别 | 导通角 $\theta$ | 理论最大效率 | 线性度 | 适用 |
|------|----------------|-------------|--------|------|
| **Class A** | 360° | 50%（实际~25%） | 优 | 高线性、低功率 |
| **Class AB** | 180°~360° | 50%~78.5%（~50%） | 良 | 主流线性 PA |
| **Class B** | 180° | 78.5% | 中（交越失真） | 推挽 PA |
| **Class C** | <180° | >78.5%（接近100%） | 差（需调谐） | 恒包络（FM） |
| **Class D** | 开关 | >90% | 差 | 恒包络 |
| **Class E** | 开关 | >90% | 差 | 恒包络，调谐负载 |
| **Class F** | 开关 + 谐波调谐 | >80% | 差 | 高效率 |
| **Class F$^{-1}$** | 逆 F | >85% | 差 | 高效率 |

#### 6.2.1 Class A 效率推导

设输出最大正弦摆幅为 $V_{DD}$，负载电阻 $R_L$，静态电流 $I_{DC} = V_{DD}/R_L$：

$$
P_{out,max} = \frac{V_{DD}^2}{2R_L}, \quad P_{DC} = \frac{V_{DD}^2}{R_L}
$$

$$
\eta_{A,max} = \frac{P_{out,max}}{P_{DC}} = 50\%
$$

实际中考虑到电压裕度与饱和，效率约 25~35%。

#### 6.2.2 Class B 推挽效率

推挽结构每管导通半周期，输出傅里叶基波电流为 $\frac{I_{max}}{2}$，直流为 $\frac{I_{max}}{\pi}$：

$$
P_{out} = \frac{V_{DD}I_{max}}{4}, \quad P_{DC} = \frac{V_{DD}I_{max}}{\pi}
$$

$$
\eta_{B,max} = \frac{\pi}{4} \approx 78.5\%
$$

#### 6.2.3 Class E 开关型 PA

利用开关管 + 谐振负载网络，使开关在零电压零导数下切换（ZVS/ZdVS），消除开关损耗，理论效率可达 100%。设计公式（简化）：

$$
R_{opt} = \frac{8}{\pi^2+4}\frac{V_{DD}^2}{P_{out}}, \quad L_{choke} \gg R_{opt}/\omega
$$

#### 6.2.4 Class F 谐波调谐

输出网络对基波负载、对二次谐波短路、对三次谐波开路，使漏极电压近似方波（含三次谐波），效率可达 88%。

### 6.3 PA设计考虑

#### 6.3.1 负载线匹配（Load-Line Matching）

为获得最大功率输出，PA 输出阻抗应满足**负载线匹配条件**：

$$
R_{opt} = \frac{V_{DD} - V_{knee}}{I_{max}/2}
$$

其中 $V_{knee}$ 为晶体管的膝电压（饱和压降）。该阻抗通常远低于 50Ω（典型 1~10Ω），需通过**输出匹配网络**（变压器、π网络、巴伦）将 $R_{opt}$ 变换到 50Ω 天线负载。

#### 6.3.2 稳定性

PA 高增益 + 强非线性易引发不稳定（振荡）：

- 加基极/栅极镇流电阻（增大稳定性，损失增益）
- 输入/输出端串联铁氧体珠或 RC 网络
- 中和电容（Neutralization）抵消 $C_{gd}$ 反馈
- 仿真 $K$ 因子和 $\mu$ 因子需 > 1

#### 6.3.3 热设计

PA 是芯片中功耗密度最高的模块：

$$
T_j = T_a + P_{diss}\cdot R_{\theta,JA}
$$

- $R_{\theta,JA}$ 为结到环境热阻
- 高温导致 $V_{TH}$ 漂移、$g_m$ 下降、寿命缩短（Arrhenius 定律：每升高 10°C，寿命减半）
- 措施：增大发射极面积、并联多指、合理分布散热、加散热过孔阵列

### 6.4 PA线性化技术

为提升线性 PA 在高效率工作点下的线性度，采用**线性化技术**：

| 技术 | 原理 | 优势 | 劣势 |
|------|------|------|------|
| **预失真（PD）** | 输入端施加反向非线性 | 简单、低功耗 | 带宽受限、对温度敏感 |
| **反馈法** | 检测输出并反馈 | 精度高 | 带宽受限、稳定性 |
| **前馈法** | 误差提取并相减 | 宽带、高线性 | 电路复杂、效率低 |
| **EER** | 包络与相位分离，包络调制电源 | 高效率 | 带宽受限、延迟匹配难 |
| **Doherty** | 主+辅 PA 协同 | 6dB 回退效率高 | 调谐复杂、带宽窄 |
| **数字预失真 DPD** | 数字域补偿非线性 | 灵活、精度高 | 需高速 DAC、复杂算法 |

#### 6.4.1 Doherty PA

由载波 PA（Class AB）和峰值 PA（Class C）组成，通过 $90°$ 相移合成网络并联：

```
         ┌── 载波PA (Class AB) ── 1/4λ ──┐
输入 ─────┤                                 ├──→ 输出
         └── 峰值PA (Class C) ─────────────┘
```

**优势**：在 6 dB 输出回退点仍保持高效率（约 60%），适合高峰均比（PAPR）信号如 OFDM。

#### 6.4.2 EER（Envelope Elimination and Restoration）

将 RF 信号分解为**相位**（限幅后的恒包络）和**包络**两路：

- 相位路径：驱动开关型 PA（Class E）
- 包络路径：调制 PA 电源电压 $V_{DD}$

PA 始终工作于高效率开关状态，线性由电源调制决定。挑战是包络带宽需为 RF 信号带宽的 3~5 倍。

### 6.5 CMOS PA 的挑战

| 挑战 | 原因 | 解决方案 |
|------|------|---------|
| **低击穿电压** | 深亚微米工艺 $V_{bk}$ ~1~2V | cascode、堆叠 FET、变压器合成 |
| **衬底损耗** | 低阻衬底耦合到地 | 高阻衬底、ESD 保护优化 |
| **低 $g_m$** | CMOS 跨导低 | 多级驱动、器件并联 |
| **无源器件 Q 低** | 片上电感 Q < 15 | 外置匹配、键合线电感 |
| **热阻高** | CMOS 衬底导热差 | 多指布局、散热过孔 |
| **1/f 噪声上变频** | 影响近载波相位噪声 | 大器件、差分结构 |

#### 6.5.1 变压器合成（Power Combining）

将多个低功率 PA 单元输出通过变压器合成，提高总输出功率并降低单管压力：

- **分布式有源变压器（DAT）**：多个 PA 单元环形排列，输出变压器合成
- **堆叠 FET**：多个低压晶体管串联承受高压，等效提升击穿电压
- **并联合成**：Wilkinson/分支线耦合器合成

### 6.6 设计实例（2.4GHz CMOS PA）

**规格**：2.4 GHz ISM 频段，$P_{out}$=+20 dBm，PAE>30%，增益>20 dB，1.2V CMOS 工艺。

**设计**：

1. **拓扑**：Class AB 两级 cascode（驱动级 + 功放级）
2. **堆叠**：功放级用 3 个 cascode 串联以承受 3.6V 摆幅
3. **输出合成**：分布式有源变压器，3 路合成
4. **阻抗变换**：$R_{opt} \approx 4\Omega$ → 50Ω，匝比 1:3.5
5. **稳定**：输入串联 5Ω 镇流电阻，栅极去耦
6. **线性化**：数字预失真 DPD，ACLR 由 -32 dBc 改善至 -48 dBc

**仿真结果**：$P_{sat}$=+22 dBm，$P_{1dB}$=+19 dBm，PAE=34%，Gain=24 dB，ACLR=-48 dBc（DPD）。

## 7. 射频频率综合器

频率综合器是 RF 收发机的"心脏"，为混频器提供精确、低噪声的本振（LO）信号。其相位噪声、杂散和锁定时间是 RF 系统性能的关键。

### 7.1 频率综合器在 RF 收发机中的角色

| 角色 | 说明 |
|------|------|
| **本振产生** | 为 RX/TX 混频器提供 LO，频率 = RF ± IF |
| **信道选择** | 通过改变分频比 N 切换通信信道 |
| **频段切换** | 覆盖多频段（如 2.4G/5G Wi-Fi） |
| **调制/解调** | 在锁相调制器中，LO 本身承载调制信息 |
| **时钟生成** | 为基带、ADC/DAC 提供同步时钟 |

### 7.2 整数 N 频率综合器

经典整数 N PLL 结构：

```
fref ──→ [PFD] ──→ [CP] ──→ [LF] ──→ [VCO] ──→ fout
          ↑                                  ↓
          └──────── [÷N] ←───────────────────┘
```

锁定时：

$$
f_{out} = N \cdot f_{ref}
$$

- **频率分辨率** = $f_{ref}$ = 信道间隔
- **优势**：结构简单、杂散可控
- **劣势**：分辨率受限（窄信道要求低 $f_{ref}$，恶化相位噪声）；锁定时间长

### 7.3 小数 N 频率综合器

通过让分频比在 N 与 N+1 之间**动态切换**，实现非整数（小数）分频：

$$
f_{out} = (N + F)\cdot f_{ref}, \quad F\in[0,1)
```

其中 F 由 ΣΔ 调制器控制，平均分频比为 $N+F$。

#### 7.3.1 ΣΔ 调制小数分频

ΣΔ 调制器产生高速、过采样的 0/1 控制信号，控制分频器在 N 与 N+1 间切换：

- **优势**：将量化噪声**高阶噪声整形**到高频，环路滤波器滤除
- **典型结构**：3 阶 MASH（Multi-stAge noise SHaping）ΣΔ 调制器
- **分辨率**：取决于 ΣΔ 位宽，可达 Hz 级

输出相位噪声（ΣΔ 贡献）：

$$
\mathcal{L}_{\Sigma\Delta}(f) = \frac{(2\pi)^2}{12 f_{ref}}\cdot\left|H_{CL}(f)\right|^2 \cdot \left[2\sin\left(\frac{\pi f}{f_{ref}}\right)\right]^{2L}
$$

其中 $H_{CL}$ 是 PLL 闭环传递函数，$L$ 是 ΣΔ 调制器阶数。

#### 7.3.2 杂散问题

小数 N PLL 的主要杂散来源：

- **小数杂散**：F 接近简单分数（如 0.5）时，周期性切换产生杂散
- **ΣΔ 自杂散**：ΣΔ 内部状态周期性产生
- **减小方法**：扰乱 ΣΔ、加 dither、增大环路带宽远离散杂频

### 7.4 RF VCO 设计

VCO 详细设计已在 10.3 章覆盖，此处仅讨论 RF 应用要点。

#### 7.4.1 LC-VCO 调谐范围

RF VCO 通常采用 LC 谐振结构，调谐通过变容管实现：

$$
f_{osc} = \frac{1}{2\pi\sqrt{L(C_{fix}+C_{var}+C_{par})}}
$$

调谐范围（百分比）：

$$
TR = \frac{f_{max} - f_{min}}{f_{center}}\times 100\%
$$

宽频段应用（如 5G Wi-Fi 4.9~7.1 GHz）需要 TR > 40%，要求：
- 高 $C_{var}/C_{fix}$ 比
- 切换电容阵列（粗调）+ 变容管（细调）
- 优化谐振器 Q 值

#### 7.4.2 相位噪声要求

相位噪声由 Leeson 公式描述：

$$
\mathcal{L}(f_m) = 10\log\left[\frac{FkT}{P_{sig}}\left(1+\left(\frac{f_0}{2Q\cdot f_m}\right)^2\right)\left(1+\frac{f_c}{f_m}\right)\right]
```

其中 $Q$ 是谐振器有载 Q 值，$P_{sig}$ 是谐振腔功率，$f_c$ 是 1/f 噪声转角频率。

**RF 系统的相位噪声要求示例**（GSM）：在 600 kHz 偏移处 < -133 dBc/Hz，对 VCO 设计要求极高。

#### 7.4.3 VCO 缓冲设计

VCO 输出需经缓冲器驱动混频器和分频器：

- **隔离**：防止负载变化牵引 VCO 频率（负载牵引）
- **电平转换**：将 VCO 摆幅转换为混频器/分频器所需电平
- **阻抗匹配**：提供 50Ω 或差分输出
- **典型结构**：源极跟随器、差分对、CMOS 反相器链

### 7.5 分频器设计

#### 7.5.1 CML 分频器（高频）

电流模逻辑（CML）分频器采用差分对 + 锁存器结构，工作频率可达 60+ GHz：

```
LO ──→ [CML 锁存器1] ──→ [CML 锁存器2] ──→ ÷2 输出
          ↑──────────────┘（交叉耦合）
```

- **优点**：高速、低相位噪声
- **缺点**：静态电流大、功耗高
- **应用**：高频预分频（如 60 GHz 输入 ÷2 → 30 GHz）

#### 7.5.2 静态分频器

由标准 D 触发器构成，最大工作频率约 5~20 GHz：

- **优点**：低功耗、任意分频比可编程
- **缺点**：速度受限
- **应用**：低频段分频

#### 7.5.3 多模分频器（MMD）

由多个 2/3 分频单元级联，实现任意整数分频：

$$
N = 2^{n} + p_0 \cdot 2^{0} + p_1 \cdot 2^{1} + \cdots + p_{n-1} \cdot 2^{n-1}
$$

- **优点**：完全可编程、面积小
- **缺点**：最大频率受限（<10 GHz），需前置高速预分频

### 7.6 频率综合器指标

| 指标 | 定义 | 典型值 |
|------|------|--------|
| **相位噪声** | 偏移载波一定频率处的噪声密度 | -90 ~ -130 dBc/Hz @ 1MHz |
| **杂散** | 离散干扰分量 | < -60 dBc |
| **锁定时间** | 切换信道到稳态所需时间 | 10~500 μs |
| **频率分辨率** | 最小频率步进 | 1 Hz ~ 100 kHz |
| **频率范围** | LO 可输出频率范围 | 1~2 倍频程 |
| **功耗** | 总功耗 | 10~50 mW |

**相位噪声预算示例**（5 GHz WLAN LO）：

| 偏移频率 | 相位噪声目标 |
|---------|-------------|
| 10 kHz | -70 dBc/Hz |
| 100 kHz | -90 dBc/Hz |
| 1 MHz | -115 dBc/Hz |
| 10 MHz | -135 dBc/Hz |

## 8. RF发射机架构

发射机的核心任务是将基带信号**上变频**到射频，并放大到天线所需的功率水平，同时满足频谱掩码、ACLR 和 EVM 等指标。

### 8.1 直接上变频（Direct Conversion Transmitter）

```
DAC ──→ 基带滤波 ──→ I/Q 上变频 ──→ 合成 ──→ 可变增益放大 ──→ PA ──→ 天线
                       ↑
                     LO = fRF
```

**优点**：

- 结构简单，无中频，无镜像问题
- 频率切换灵活，多频段适用
- 易集成，成本低

**挑战**：

- **LO 泄漏**：LO 直接等于 RF，易通过 PA/开关泄漏到天线，造成载波泄漏
- **镜像抑制**：依赖 I/Q 平衡，要求 IRR > 40 dB
- **本振牵引**：PA 大信号可能牵引 VCO 频率
- **频谱再生**：PA 非线性导致 ACLR 恶化

### 8.2 偏移锁相发射机（Offset-PLL Transmitter）

将 VCO 锁相到偏离载波的参考频率，避免 PA 牵引：

```
fref ──→ [PFD] ──→ [LF] ──→ [VCO] ──→ PA ──→ 天线
          ↑                       ↓
          └─ [÷N] ←─ [混频] ←─ f_offset
```

**优点**：VCO 输出已是高质量射频信号，PA 直接放大即可；高线性度由 PLL 环路保证。

**缺点**：仅适合恒包络信号（如 GMSK），不适合非恒包络（如 OFDM），需结合极化调制。

### 8.3 极化调制发射机

将信号分解为幅度 $A(t)$ 和相位 $\phi(t)$ 两路：

$$
s(t) = A(t)\cos(\omega_c t + \phi(t))
```

- **相位路径**：调制 VCO 相位（直接锁相或 PLL 调制）
- **幅度路径**：调制 PA 电源电压（如 EER/ET）

**优点**：PA 可工作于高效率开关模式；适合高峰均比信号。

**缺点**：幅度/相位路径需精确时间对齐；带宽扩展问题（包络带宽是 RF 带宽的 3~5 倍）。

### 8.4 发射机挑战

| 挑战 | 原因 | 缓解 |
|------|------|------|
| **LO 泄漏** | LO 与 RF 同频，DC 偏移上变频 | I/Q 校准、LO 偏移、隔离 |
| **镜像抑制** | I/Q 失配产生镜像 | 校准、几何匹配 |
| **ACLR（邻道泄漏）** | PA 非线性导致频谱扩展 | DPD、线性 PA |
| **EVM** | 相位噪声、I/Q 失配、非线性 | 优化 LO、校准、DPD |
| **PA 牵引** | PA 大信号耦合到 VCO | 偏移锁相、隔离、屏蔽 |
| **噪声本底** | PA 噪声底抬升邻道 | 低噪声 PA 设计、滤波 |

## 9. RFIC设计流程与工具

### 9.1 射频IC设计与低频IC的区别

| 维度 | 低频/数字 IC | RFIC |
|------|-------------|------|
| **频率范围** | DC ~ 几 GHz | 数百 MHz ~ 数百 GHz |
| **设计方法** | 时序驱动、SPICE | S 参数、谐波平衡 |
| **寄生效应** | 集总参数 | 分布参数、传输线 |
| **无源器件** | 电阻、电容为主 | 电感、变压器、传输线主导 |
| **测量** | 时域为主 | 频域为主（VNA、频谱仪） |
| **版图** | 自动 P&R | 手工布局，EM 仿真 |
| **仿真工具** | SPICE、HSPICE | SpectreRF、ADS、HFSS |

### 9.2 S参数仿真

S 参数（散射参数）是 RF/微波频段最自然的二端口网络描述：

$$
\begin{bmatrix} b_1 \\ b_2 \end{bmatrix} = \begin{bmatrix} S_{11} & S_{12} \\ S_{21} & S_{22} \end{bmatrix} \begin{bmatrix} a_1 \\ a_2 \end{bmatrix}
```

| 参数 | 物理意义 |
|------|---------|
| $S_{11}$ | 输入反射系数（输入匹配） |
| $S_{22}$ | 输出反射系数（输出匹配） |
| $S_{21}$ | 正向传输（增益） |
| $S_{12}$ | 反向传输（隔离度） |

与阻抗/导纳参数的关系（归一化到 $Z_0=50\Omega$）：

$$
S_{11} = \frac{Z_{in}-Z_0}{Z_{in}+Z_0}
```

**稳定性判定**：Rollet 因子

$$
K = \frac{1 - |S_{11}|^2 - |S_{22}|^2 + |\Delta|^2}{2|S_{12}S_{21}|} > 1, \quad \Delta = S_{11}S_{22}-S_{12}S_{21}
$$

且 $|\Delta| < 1$ 时网络无条件稳定。

### 9.3 谐波平衡仿真（Harmonic Balance）

谐波平衡法（HB）是 RF 仿真中求解**非线性周期稳态**的核心方法：

- **原理**：将电路信号用傅里叶级数展开，频域方程在多个谐波上同时满足 KCL
- **适用**：功率放大器、混频器、振荡器的稳态分析
- **优势**：相比瞬态仿真，HB 直接得到稳态频谱，速度快，精度高
- **输出**：各次谐波幅度/相位、压缩点、交调、相位噪声

典型 HB 设置：基频 $f_0$ + 多次谐波（如 5~10 次）+ 多音（多 RF 输入，用于 IM3 仿真）。

### 9.4 包络仿真（Envelope Simulation）

包络仿真用于**调制信号**下 RF 电路的时-频联合分析：

- 将信号表示为载波 $\cos(\omega_c t)$ 与缓慢包络 $A(t)$ 的乘积
- 载波在频域用 HB 求解，包络在时域用 SPICE 求解
- 适用：EVM、ACLR、邻道功率、星座图分析
- 比 HB 多音仿真快得多，比瞬态仿真准确得多

### 9.5 电磁仿真（EM Simulation）

片上电感、变压器、传输线、键合线等无源器件需用 EM 仿真提取 S 参数：

| 方法 | 适用 | 特点 |
|------|------|------|
| **Momentum（MoM）** | 平面 2.5D 结构 | 速度快，片上无源首选 |
| **HFSS（FEM）** | 三维结构 | 精度高，封装/键合线 |
| **EMX** | 片上平面结构 | 与 Cadence 集成 |
| **FDTD** | 时域宽带 | 适合瞬态/宽带 |

**流程**：版图 → EM 工具提取 S 参数 → 创建符号化模型 → 嵌入原理图 → 联合仿真。

| 工具 | 厂商 | 用途 |
|------|------|------|
| **Virtuoso** | Cadence | 原理图/版图设计平台 |
| **SpectreRF** | Cadence | HB、包络、噪声仿真 |

## 10. RFIC版图设计要点

RFIC 的性能在很大程度上取决于版图质量。一个好的 RF 版图可将寄生效应、失配和耦合降到最低，而糟糕的版图可使精心设计的电路性能减半。

### 10.1 射频器件布局

**关键原则**：

1. **信号路径最短**：RF 走线越短，寄生电感/电容越小
2. **避免直角走线**：直角导致阻抗突变，使用 45° 或圆弧
3. **共面波导（GCPW）**：信号线两侧紧邻接地，电磁场约束好，适合 RF
4. **对称布局**：差分电路严格镜像，I/Q 通道对称
5. **大电流路径加宽**：PA 走线需承载大电流，宽度按 $J_{max}$ 设计
6. **避免交叉**：RF 走线避免跨越，必要时用多层金属

### 10.2 衬底隔离

CMOS 衬底是公共的，数字噪声通过衬底耦合到 RF：

| 技术 | 说明 |
|------|------|
| **保护环（Guard Ring）** | 周围掺杂环形扩散，连接地/电源 |
| **深 N 阱（Deep NWell）** | 将器件与衬底隔离 |
| **衬底接触阵列** | 多点接地降低衬底阻抗 |
| **高阻衬底** | 工艺选择（>1 kΩ·cm） |
| **SOI 工艺** | 完全介电隔离，性能优但成本高 |
| **屏蔽层（Shielding）** | 关键节点下方加接地多晶硅层 |

### 10.3 电源去耦

RF 电路对电源噪声极为敏感，需多层次去耦：

```
                  片上去耦电容
VDD ── Bondwire ──┬── 100pF (nF MIM) ──┬── 电路
                  |                      |
                10nF                  1pF
                (片上)              (高频)
                  |
              PCB 1μF (陶瓷)
```

- **片上去耦**：MOM/MIM 电容，10pF~1nF，紧邻电路放置
- **多层并联**：不同容值覆盖不同频段，避免并联谐振
- **键合线电感**：每根键合线 ~1 nH，与去耦电容形成谐振，需仔细设计

### 10.4 屏蔽与接地

| 屏蔽对象 | 方法 |
|---------|------|
| **RF 信号线** | 上下层接地金属，侧壁接地过孔 |
| **电感** | 保持远离其他金属，下方加图案接地屏蔽（PGS） |
| **敏感节点（如 VCO 控制电压）** | 全屏蔽，独立电源域 |
| **数字/RF 边界** | 深 N 阱 + 保护环 + 物理距离 > 100μm |

**接地策略**：

- 多点接地 vs 单点接地：高频下多点接地更优
- 数字地与模拟地分离，单点汇合
- 大面积接地金属层降低电感

### 10.5 无源器件版图

#### 10.5.1 螺旋电感

片上电感普遍采用八角形/方形螺旋结构：

| 设计参数 | 影响 |
|---------|------|
| **圈数 N** | 电感量 ↑，但电阻与寄生电容也 ↑ |
| **线宽 W** | Q ↑（电阻 ↓），但面积 ↑ |
| **间距 S** | 互感 ↑，但耦合电容 ↑ |
| **内径 $D_{in}$** | 内圈电阻大、贡献小，需折中 |
| **金属层** | 顶层金属最厚，Q 最高 |

**改良**：

- **对称差分电感**：单端结构 vs 差分结构，差分结构 Q 提升 20~40%
- **堆叠电感**：多层并联降低电阻，提高 Q
- **图案接地屏蔽（PGS）**：降低衬底损耗，但增加寄生电容

电感值估算（Wheeler 公式近似）：

$$
L \approx \frac{\mu_0 N^2 d_{avg}}{2}\left[\ln\left(\frac{2.46}{\rho}\right) + 0.20\rho^2\right]
$$

其中 $d_{avg}$ 为平均直径，$\rho = (d_{out}-d_{in})/(d_{out}+d_{in})$ 为填充率。

#### 10.5.2 变压器（巴伦）

片上变压器用于**阻抗变换**、**不平衡-平衡转换**和**功率合成**：

- **结构**：两绕组耦合（同心、交织、堆叠）
- **耦合系数 $k$**：典型 0.6~0.9，取决于几何
- **匝比 $n$**：阻抗变换比 $n^2$，可升压/降压
- **应用**：PA 输出阻抗变换（1:3~1:5）、LNA 输入巴伦、功率合成

#### 10.5.3 MIM/MOM 电容

| 类型 | 单位容值 | Q 值 | 击穿电压 | 用途 |
|------|---------|------|---------|------|
| **MIM（Metal-Insulator-Metal）** | 1~5 fF/μm² | 高（>50） | 10~20V | RF 信号路径 |
| **MOM（Metal-Oxide-Metal）** | 0.5~2 fF/μm² | 中 | 中 | 通用、去耦 |
| **MOS 电容** | 5~20 fF/μm² | 低 | 低 | 大容量、去耦 |
| **可变电容（Varactor）** | — | 中 | 中 | VCO 调谐 |

RF 信号路径首选 MIM 电容（高 Q、低损耗）；电源去耦选 MOM/MOS（高密度）。

## 11. 小结

RFIC 设计是一门横跨**电路理论、电磁场、半导体物理、信号处理和系统架构**的综合性工程学科。本章系统介绍了 RFIC 设计的核心内容：

1. **架构层面**：接收机的超外差、零中频、低中频三种架构各有优劣，需根据应用场景、灵敏度、集成度和成本综合选择；发射机的直接上变频、偏移锁相、极化调制等架构在高效率与高线性度之间做出折中。

2. **核心模块**：
   - **LNA** 通过源极电感负反馈实现功率/噪声同时匹配，cascode 结构提升增益与隔离度；
   - **混频器** 的有源吉尔伯特结构提供增益但 1/f 噪声较大，无源混频器线性度高、1/f 噪声低，是零中频架构的优选；
   - **PA** 在效率与线性度间折中，Doherty、EER、DPD 等线性化技术使高效率开关型 PA 适用于非恒包络信号；
   - **频率综合器** 的小数 N 结构结合 ΣΔ 调制实现高分辨率，但需处理小数杂散。

3. **设计方法**：S 参数、谐波平衡、包络仿真、EM 仿真构成 RFIC 仿真的核心工具链；版图设计中衬底隔离、电源去耦、屏蔽与接地、无源器件优化直接决定芯片性能。

4. **CMOS RFIC 的演进**：随着 CMOS 工艺的进步，单芯片射频收发机已广泛应用于无线通信领域；但低击穿电压、衬底损耗、低 Q 无源器件等挑战依然存在，需要通过堆叠 FET、变压器合成、SOI 等技术解决。

RFIC 设计的本质是**多目标优化**：在频率、带宽、噪声、线性度、增益、效率、面积、成本之间寻找最佳平衡点。设计者既需扎实的理论基础，也需丰富的工程经验。随着 5G/6G、物联网、毫米波雷达等应用的快速发展，RFIC 设计将继续是微电子领域最具挑战与机遇的方向之一。
