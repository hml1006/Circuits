# 17.1 MEMS基础

## 1. 引言

微机电系统（Micro-Electro-Mechanical Systems, MEMS）是将微型机械结构与电子电路集成在同一芯片上的系统级技术。如果说集成电路（IC）实现了"微型化的电子运算"，那么 MEMS 则在此基础上实现了"微型化的感知与执行"——通过在硅片上构建可动的机械结构（梁、膜、齿轮、悬臂等），实现对力、加速度、角速度、压力、声波、流体等物理量的传感与操控。

MEMS 的核心理念是**与 IC 工艺兼容**：利用半导体制造中的光刻、刻蚀、沉积等工艺，在硅片上批量制造微米尺度的机械结构，从而继承 IC 产业高精度、低成本、大批量的优势。从 1980 年代初期的压力传感器起步，到如今智能手机中动辄包含十数颗 MEMS 芯片（加速度计、陀螺仪、麦克风、气压计等），MEMS 已成为"超越摩尔"（More-than-Moore）路线的典范。

MEMS 技术横跨**机械学、流体力学、电磁学、材料科学和集成电路设计**等多学科领域，其设计流程涉及力学仿真、有限元分析、工艺仿真和电路设计的协同。本章将系统介绍 MEMS 的工艺技术、力学基础、传感器与执行器原理、RF MEMS、谐振器、封装和设计流程，为读者建立完整的 MEMS 知识体系。

## 2. MEMS概述

### 2.1 MEMS的定义

MEMS 是在微米至毫米尺度上，将**机械（可动）结构**、**传感器**、**执行器**和**信号处理电路**集成在同一芯片或同一封装内的微型系统。其特征包括：

| 特征 | 说明 |
|------|------|
| **微型化** | 特征尺寸在 1 μm ~ 1 mm 范围 |
| **可动机械结构** | 区别于纯电子 IC，MEMS 包含可运动的机械部件 |
| **与 IC 工艺兼容** | 采用半导体制造工艺，可批量生产 |
| **机电耦合** | 机械量与电学量之间相互转换（传感或执行） |
| **系统集成** | 传感器 + 执行器 + 信号处理 + 控制电路的集成 |

MEMS 的核心在于**机电转换**：传感器将机械量（力、位移、压力等）转换为电信号，执行器将电信号转换为机械运动。

### 2.2 MEMS与IC的关系

MEMS 与 IC 共享半导体制造工艺平台，但两者在设计理念上有本质差异：

| 维度 | IC（集成电路） | MEMS（微机电系统） |
|------|---------------|-------------------|
| **核心功能** | 电子信号处理 | 机械感知/执行 |
| **结构特点** | 固态，无可动部件 | 包含可动结构（梁、膜、齿轮等） |
| **设计方法** | EDA 自动化程度高 | 有限元（FEM）+ 电路协同仿真 |
| **工艺流程** | 标准化（前道/后道） | 非标准，需定制工艺模块 |
| **封装要求** | 电互连 + 保护 | 需考虑机械自由度、真空、气密性 |
| **可靠性** | 电学可靠性为主 | 电学 + 机械可靠性（疲劳、磨损、粘连） |
| **设计规则** | DRC 规则成熟 | 尚无统一 DRC，需工艺验证 |

**关键联系**：MEMS 器件需要信号读出与控制电路，因此 MEMS 与 IC 的集成（单芯片或系统级封装 SiP）是 MEMS 产品的关键发展方向。

### 2.3 MEMS应用领域

MEMS 已渗透到诸多领域，形成了多样化的产品生态：

| 应用领域 | 典型器件 | 应用场景 |
|---------|---------|---------|
| **惯性传感器** | 加速度计、陀螺仪 | 手机、汽车、无人机、游戏手柄 |
| **压力传感器** | 压阻式/电容式压力传感器 | 轮胎气压、血压计、工业过程控制 |
| **声学器件** | MEMS 麦克风 | 手机、助听器、智能音箱 |
| **微流体** | 微泵、微阀、微通道 | 生物医学分析、药物递送 |
| **RF MEMS** | 开关、可变电容、电感、谐振器 | 5G/6G 射频前端、可重构天线 |
| **BioMEMS** | 生物传感器、微针阵列、Lab-on-a-Chip | 基因测序、即时诊断（POCT） |
| **光学 MEMS** | DMD 微镜阵列、微扫描镜 | 投影仪、AR/VR、激光雷达 |
| **热学 MEMS** | 微热板、红外探测器 | 气体传感器、热成像 |
| **打印头** | 热泡喷墨打印头 | 喷墨打印机 |

### 2.4 MEMS市场规模与发展趋势

| 年份 | 全球 MEMS 市场规模 | 驱动力 |
|------|-------------------|--------|
| 2015 | ~120 亿美元 | 智能手机普及、汽车电子化 |
| 2020 | ~150 亿美元 | TWS 耳机、IoT 传感节点 |
| 2025 | ~200 亿美元（预估） | 5G 射频前端、自动驾驶、AR/VR |
| 2030 | ~300 亿美元（预估） | 智能感知无处不在、BioMEMS 崛起 |

**发展趋势**：

1. **多传感器融合**：单一封装内集成加速度计 + 陀螺仪 + 磁力计（9 轴 IMU）
2. **更高性能**：导航级陀螺仪（零偏稳定性 < 1°/h）、高精度气压计
3. **更小尺寸**：从 3×3 mm² 向 2×2 mm² 甚至更小演进
4. **更低功耗**：常开（Always-On）传感器功耗降至 μW 级
5. **压电 MEMS 兴起**：AlN/PZT 压电材料实现更低驱动电压、更高响应
6. **MEMS + AI**：边缘智能感知，传感器内嵌 AI 加速器

## 3. MEMS工艺技术

MEMS 工艺的核心任务是**在硅片上构建可动的三维机械结构**。与 IC 工艺的平面化加工不同，MEMS 需要形成悬空、空腔和可动部件，这就要求专门的微加工技术。

### 3.1 体硅微加工（Bulk Micromachining）

体硅微加工通过**选择性地去除硅衬底材料**来形成三维结构，是 MEMS 最早发展起来的加工技术。

#### 3.1.1 各向异性湿法腐蚀

单晶硅在不同晶面上的腐蚀速率差异极大，利用这一特性可实现高精度的三维结构：

| 腐蚀液 | 腐蚀速率比 $\frac{R(100)}{R(111)}$ | 特点 | 选择比 |
|--------|-------------------------------------|------|--------|
| **KOH**（氢氧化钾） | ~100:1 ~ 600:1 | 成本低、腐蚀速率快；金属不兼容 | SiO₂ 掩模选择比 ~200:1 |
| **TMAH**（四甲基氢氧化铵） | ~30:1 ~ 100:1 | 与 IC 兼容（无碱金属离子）；腐蚀速率较慢 | SiO₂ 掩模选择比 ~1000:1 |
| **EDP**（乙二胺邻苯二酚） | ~35:1 | 选择比高；有毒，逐步淘汰 | SiO₂/Si₃N₄ 掩模 |

**(100) 硅片的各向异性腐蚀特性**：

- 腐蚀沿 <100> 方向快速进行，<111> 方向几乎停止
- 形成 V 形槽或倒金字塔形空腔，侧壁为 {111} 面，与表面夹角为 54.74°
- V 形槽开口宽度 $W$ 与深度 $d$ 的关系：

$$W = d \cdot \sqrt{2} \cdot 2 = 2\sqrt{2} \cdot d$$

- 腐蚀停止技术：重掺杂硼（$p^{++}$，浓度 > $5 \times 10^{19}$ cm⁻³）可使腐蚀速率降低 50~100 倍，实现自停止腐蚀

#### 3.1.2 深反应离子刻蚀（DRIE）

DRIE 是体硅微加工中最重要的干法刻蚀技术，可实现**高深宽比（High Aspect Ratio）**的垂直结构。主流工艺为 **Bosch 工艺**（由 Robert Bosch 公司发明）：

**Bosch 工艺原理**——交替进行刻蚀与钝化：

```
周期性循环：
  ┌─ 刻蚀步骤：SF₆ 等离子体，各向同性刻蚀硅（~10-15 秒）
  │                 ↕
  └─ 钝化步骤：C₄F₈ 等离子体，在侧壁沉积氟碳聚合物保护层（~7-10 秒）
```

**关键指标**：

| 参数 | 典型值 | 说明 |
|------|--------|------|
| **刻蚀速率** | 5~30 μm/min | 与刻蚀面积有关（Loading Effect） |
| **深宽比** | 10:1 ~ 30:1（典型），最高可达 50:1+ | 深度/宽度 |
| **侧壁垂直度** | 89° ~ 90°（±1°） | 侧壁倾角 |
| **侧壁粗糙度** | 0.1~0.5 μm（扇贝纹） | 刻蚀-钝化交替产生的波纹 |
| **均匀性** | ±2%~5%（6英寸片） | 片内均匀性 |

**扇贝纹（Scalloping）**：Bosch 工艺的固有特征，每个刻蚀-钝化周期在侧壁产生一个微小凹痕，深度约 50~200 nm。对光学应用和低损耗 RF MEMS 不利，可通过优化参数减小。

**刻蚀速率与面积的关系（Loading Effect）**：

$$R_{etch} = \frac{R_0}{1 + \alpha \cdot A_{exposed}}$$

其中 $R_0$ 为小面积刻蚀速率，$A_{exposed}$ 为暴露硅面积，$\alpha$ 为负载系数。

### 3.2 表面微加工（Surface Micromachining）

表面微加工在硅衬底表面逐层构建结构，通过**牺牲层技术**释放可动部件，不大量去除衬底材料。

#### 3.2.1 牺牲层技术（Sacrificial Layer）

表面微加工的基本流程：

```
1. 在衬底上沉积牺牲层材料（如 SiO₂，1~2 μm）
2. 光刻并刻蚀牺牲层，形成锚点（Anchor）窗口
3. 沉积结构层材料（如多晶硅，1~5 μm）
4. 光刻并刻蚀结构层，形成梁、膜等机械结构
5. 选择性腐蚀牺牲层，释放结构层（Release）
```

**关键材料组合**：

| 牺牲层 | 结构层 | 释放腐蚀液 | 特点 |
|--------|--------|-----------|------|
| SiO₂（LTO/PSG） | 多晶硅（Poly-Si） | HF（氢氟酸） | 最经典组合，SUMMiT 工艺 |
| 光刻胶（PR） | 金属（Au/Al） | 丙酮/O₂ 等离子体 | 简单快速，但结构层温度受限 |
| 聚酰亚胺 | 金属/氮化硅 | O₂ 等离子体 | 厚牺牲层 |
| Cu | 氮化硅/多晶硅 | FeCl₃/HNO₃ | 用于金属牺牲层工艺 |
| a-Si（非晶硅） | SiN（氮化硅） | XeF₂ 气相刻蚀 | 干法释放，避免粘连 |

#### 3.2.2 结构层释放与粘连问题

释放过程中，液体腐蚀液的表面张力会将悬空结构拉向衬底，导致**粘连（Stiction）**——这是表面微加工最致命的可靠性问题。

**粘连的物理机制**：

$$F_{capillary} = \frac{4\gamma A}{d^2}$$

其中 $\gamma$ 为液体表面张力（水：72 mN/m），$A$ 为结构面积，$d$ 为间隙。

**防粘连技术**：

| 方法 | 原理 | 效果 |
|------|------|------|
| **临界点干燥（CPD）** | 用 CO₂ 超临界干燥，消除液-气界面 | 最有效，但设备贵 |
| **升华干燥** | 用叔丁醇/对二氯苯升华干燥 | 简单，效果较好 |
| **自组装单分子层（SAM）** | OTS/FDS 涂覆降低表面能 | 长期有效 |
| **疏水涂层** | 氟碳聚合物涂层 | 工艺兼容性好 |
| **干法释放** | XeF₂ 气相刻蚀，全程无液体 | 根本避免毛细力 |
| **结构设计** | 增加支撑柱、减小米纳面积 | 辅助措施 |

### 3.3 LIGA工艺

LIGA（Lithographie, Galvanoformung, Abformung）是德语缩写，意为**光刻-电铸-注塑**，是一种可制造高深宽比金属微结构的工艺：

| 步骤 | 内容 | 说明 |
|------|------|------|
| **L——深度X射线光刻** | 同步辐射 X 射线曝光厚光刻胶（PMMA，厚度达 1 mm） | 深宽比可达 100:1 |
| **I——电铸** | 在光刻胶模具中电铸金属（Ni、Cu、Au） | 形成金属微结构 |
| **G——注塑** | 以金属结构为模具，注塑复制大批量零件 | 低成本批量生产 |

**LIGA 与硅基微加工对比**：

| 特性 | 硅基微加工 | LIGA |
|------|-----------|------|
| 材料 | 硅、多晶硅、氮化硅 | 金属（Ni/Cu/Au）、塑料 |
| 深宽比 | ~30:1（DRIE） | ~100:1 |
| 侧壁粗糙度 | 中（DRIE 有扇贝纹） | 极好（X 射线光刻） |
| 设备成本 | 中等 | 极高（需同步辐射光源） |
| 批量生产 | 晶圆级 | 模具注塑 |
| 典型应用 | 传感器、执行器 | 微齿轮、微连接器、微流体 |

**准 LIGA（UV-LIGA）**：用紫外光刻替代 X 射线光刻，使用厚胶（SU-8，厚度可达 500 μm），成本大幅降低但深宽比限制在 ~10:1。

### 3.4 键合技术

键合技术是将两片晶圆或芯片永久结合的工艺，在 MEMS 中用于形成封闭腔体、真空封装和圆片级封装。

| 键合方式 | 原理 | 温度 | 对准精度 | 特点 |
|---------|------|------|---------|------|
| **硅-硅直接键合（SDB）** | 表面活化后高温退火（>800°C），Si-O-Si 共价键 | >800°C | ±1 μm | 高强度，但温度高 |
| **阳极键合（Anodic Bonding）** | 硅片与硼硅玻璃（Pyrex 7740），加热+高压电场 | 300~450°C | ±5 μm | 简单可靠，广泛用于压力传感器 |
| **玻璃焊料键合（Glass Frit）** | 低熔点玻璃焊料（~430°C） | 400~450°C | ±10 μm | 容忍表面粗糙，气密性好 |
| **共晶键合** | Au-Si、Au-Sn 等低熔点共晶合金 | 280~400°C | ±2 μm | 导热导电，适合 RF MEMS |
| **聚合物键合** | BCB、聚酰亚胺等有机粘合剂 | 200~350°C | ±5 μm | 低温，但不气密 |
| **金属扩散键合** | Cu-Cu、Au-Au 热压扩散 | 250~400°C | ±1 μm | 气密，高可靠性 |

**阳极键合机理**：

在硅片与 Pyrex 玻璃间施加 500~1000 V 电压，加热至 300~400°C。玻璃中 Na⁺ 离子向阴极漂移，在界面处留下空间电荷区（耗尽层），产生强电场（~10⁶ V/cm），将硅与玻璃紧密吸附并通过化学键结合。

### 3.5 MEMS与CMOS集成工艺

将 MEMS 机械结构与 CMOS 电路集成在同一芯片上是实现高性能、低成本 MEMS 产品的关键路径：

| 集成方式 | 流程顺序 | 优点 | 缺点 | 代表 |
|---------|---------|------|------|------|
| **Pre-CMOS** | 先做 MEMS，再做 CMOS | MEMS 工艺灵活 | MEMS 结构可能被 CMOS 工艺损坏 | Sandia SUMMiT |
| **Intra-CMOS** | MEMS 与 CMOS 交叉进行 | 折中优化 | 流程极其复杂 | 未大规模应用 |
| **Post-CMOS** | 先做 CMOS，后做 MEMS | CMOS 工艺标准化 | MEMS 工艺受限于 CMOS 热预算（<450°C） | TI DMD、Analog Devices iMEMS |

**Post-CMOS 方案**是业界主流：先用标准 CMOS 代工完成电路，再在后道（BEOL）金属层间或开放区域加工 MEMS 结构，所有 MEMS 工艺步骤温度需控制在 450°C 以下以避免损坏 CMOS 器件。

### 3.6 工艺技术对比表

| 工艺技术 | 结构深度 | 深宽比 | 材料 | 典型结构 | 成本 |
|---------|---------|--------|------|---------|------|
| 各向异性湿法腐蚀 | 10~500 μm | 低（~1:1） | 单晶硅 | 膜片、V 形槽 | 低 |
| DRIE | 10~500 μm | 高（10:1~30:1） | 单晶硅 | 深槽、高柱、梳齿 | 中 |
| 表面微加工 | 0.5~10 μm | 中（~5:1） | 多晶硅、金属 | 悬臂梁、梳状驱动 | 中 |
| LIGA | 10~1000 μm | 极高（~100:1） | 金属、塑料 | 微齿轮、微模具 | 极高 |
| UV-LIGA | 10~500 μm | 中（~10:1） | SU-8、金属 | 微流体通道 | 中 |

## 4. MEMS力学基础

MEMS 器件的核心是可动的机械结构，其行为由弹性力学和动力学方程描述。理解力学基础是 MEMS 器件设计和仿真的前提。

### 4.1 弹性力学基础

#### 4.1.1 应力（Stress）与应变（Strain）

**应力** $\sigma$ 是单位面积上的内力：

$$\sigma = \frac{F}{A}$$

**应变** $\varepsilon$ 是相对变形量：

$$\varepsilon = \frac{\Delta L}{L_0}$$

对于各向同性弹性体，三维应力-应变关系由**广义胡克定律**描述：

$$\varepsilon_x = \frac{1}{E}[\sigma_x - \nu(\sigma_y + \sigma_z)]$$

$$\varepsilon_y = \frac{1}{E}[\sigma_y - \nu(\sigma_x + \sigma_z)]$$

$$\varepsilon_z = \frac{1}{E}[\sigma_z - \nu(\sigma_x + \sigma_y)]$$

#### 4.1.2 胡克定律

在单轴应力下，胡克定律为：

$$\sigma = E \cdot \varepsilon$$

其中 $E$ 为**杨氏模量（Young's Modulus）**，反映材料的刚度。

#### 4.1.3 MEMS常用材料力学参数

| 材料 | 杨氏模量 $E$ (GPa) | 泊松比 $\nu$ | 密度 $\rho$ (kg/m³) | 特征 |
|------|---------------------|-------------|---------------------|------|
| 单晶硅 <100> | 130 | 0.28 | 2330 | MEMS 最常用结构材料 |
| 单晶硅 <110> | 169 | 0.28 | 2330 | 各向异性 |
| 多晶硅 | ~160 | 0.22 | 2330 | 表面微加工常用 |
| 氮化硅 (Si₃N₄) | 250~320 | 0.27 | 3100 | 高刚度，低应力 |
| 二氧化硅 (SiO₂) | 70 | 0.17 | 2200 | 牺牲层/介质层 |
| 铝 (Al) | 70 | 0.35 | 2700 | 互连/反射镜 |
| 金 (Au) | 80 | 0.42 | 19300 | 高反射率/化学稳定 |
| 镍 (Ni) | 200 | 0.31 | 8900 | LIGA 结构 |
| PZT | 60~120 | 0.30 | 7600 | 压电材料 |
| AlN | 280~330 | 0.25 | 3260 | 压电材料 |

### 4.2 梁的弯曲理论

#### 4.2.1 欧拉-伯努利梁方程

MEMS 中最常用的结构是**梁**。欧拉-伯努利梁理论假设：梁的横截面在弯曲后保持平面且垂直于中性轴（适用于细长梁，$L/h > 10$）。

梁的挠度方程（四阶微分方程）：

$$EI\frac{d^4 w(x)}{dx^4} = q(x)$$

其中：
- $E$：杨氏模量
- $I$：截面惯性矩
- $w(x)$：挠度
- $q(x)$：分布载荷

矩形截面惯性矩：

$$I = \frac{bh^3}{12}$$

其中 $b$ 为梁宽，$h$ 为梁厚。

#### 4.2.2 悬臂梁挠度

一端固定、一端自由的悬臂梁，自由端施加集中力 $F$：

| 参数 | 公式 |
|------|------|
| 自由端挠度 | $w_{max} = \frac{FL^3}{3EI}$ |
| 自由端转角 | $\theta = \frac{FL^2}{2EI}$ |
| 等效弹簧常数 | $k = \frac{F}{w_{max}} = \frac{3EI}{L^3} = \frac{Ebh^3}{4L^3}$ |
| 固支端最大应力 | $\sigma_{max} = \frac{6FL}{bh^2}$ |
| 固支端弯矩 | $M_{max} = FL$ |

均匀分布载荷 $q$（单位长度力）下的悬臂梁：

$$w_{max} = \frac{qL^4}{8EI}$$

#### 4.2.3 固支梁（Double-Clamped Beam）挠度

两端固支梁，中点施加集中力 $F$：

| 参数 | 公式 |
|------|------|
| 中点挠度 | $w_{max} = \frac{FL^3}{192EI}$ |
| 等效弹簧常数 | $k = \frac{192EI}{L^3} = \frac{16Ebh^3}{L^3}$ |
| 固支端弯矩 | $M = \frac{FL}{8}$ |
| 中点弯矩 | $M = \frac{FL}{8}$ |
| 最大应力 | $\sigma_{max} = \frac{3FL}{2bh^2}$ |

**注意**：固支梁的弹簧常数是同等尺寸悬臂梁的 **64 倍**，因此固支结构更硬、更难驱动，但谐振频率更高。

#### 4.2.4 常见梁结构对比

| 梁类型 | 端部条件 | 弹簧常数 $k$ | 最大挠度（集中力 $F$） | 应用场景 |
|--------|---------|-------------|----------------------|---------|
| 悬臂梁 | 一端固支一端自由 | $3EI/L^3$ | $FL^3/(3EI)$ | AFM 探针、加速度计 |
| 固支梁 | 两端固支 | $192EI/L^3$ | $FL^3/(192EI)$ | 谐振器、滤波器 |
| 简支梁 | 两端简支 | $48EI/L^3$ | $FL^3/(48EI)$ | 桥式结构 |

### 4.3 谐振频率

#### 4.3.1 弹簧-质量系统

MEMS 的动态行为可用集总参数的弹簧-质量-阻尼系统描述：

$$m\ddot{x} + c\dot{x} + kx = F(t)$$

无阻尼固有频率：

$$f_0 = \frac{1}{2\pi}\sqrt{\frac{k}{m}}$$

阻尼系统的谐振频率：

$$f_d = f_0\sqrt{1 - \zeta^2}$$

其中 $\zeta = c/(2\sqrt{km})$ 为阻尼比。

品质因数 $Q$：

$$Q = \frac{1}{2\zeta} = \frac{\sqrt{km}}{c}$$

#### 4.3.2 悬臂梁的谐振频率

悬臂梁（均布质量 $m_b = \rho b h L$）的一阶固有频率：

$$f_1 = \frac{1}{2\pi}\cdot 1.875^2\sqrt{\frac{EI}{\rho A L^4}} = \frac{1}{2\pi}\cdot\frac{3.516}{L^2}\sqrt{\frac{EI}{\rho bh}}$$

等效弹簧-质量模型中，悬臂梁的有效质量约为总质量的 0.24 倍：

$$m_{eff} \approx 0.24 \cdot m_b = 0.24\rho bhL$$

因此：

$$f_1 = \frac{1}{2\pi}\sqrt{\frac{k}{m_{eff}}} = \frac{1}{2\pi}\sqrt{\frac{3EI/L^3}{0.24\rho bhL}} = \frac{1}{2\pi}\sqrt{\frac{Ebh^3}{0.96\rho bhL^4}}$$

#### 4.3.3 固支梁的谐振频率

固支梁的一阶固有频率：

$$f_1 = \frac{1}{2\pi}\cdot 4.730^2\sqrt{\frac{EI}{\rho A L^4}} = \frac{1}{2\pi}\cdot\frac{22.37}{L^2}\sqrt{\frac{EI}{\rho bh}}$$

比较可知，同等尺寸下固支梁的谐振频率约为悬臂梁的 **6.4 倍**。

#### 4.3.4 固有频率与模态

梁的各阶模态对应不同的振动形态，第 $n$ 阶固有频率：

$$f_n = \frac{(\beta_n L)^2}{2\pi L^2}\sqrt{\frac{EI}{\rho A}}$$

| 支撑条件 | $\beta_1 L$ | $\beta_2 L$ | $\beta_3 L$ |
|---------|-------------|-------------|-------------|
| 悬臂梁 | 1.875 | 4.694 | 7.855 |
| 固支梁 | 4.730 | 7.853 | 10.996 |
| 简支梁 | $\pi$ | $2\pi$ | $3\pi$ |

### 4.4 薄膜应力

MEMS 中的薄膜（多晶硅、氮化硅、金属等）在沉积后通常存在**残余应力**，对器件性能有重要影响。

#### 4.4.1 残余应力的来源

| 应力类型 | 来源 | 特征 |
|---------|------|------|
| **本征应力** | 沉积过程中的晶格失配、杂质、微观结构 | 与沉积条件密切相关 |
| **热失配应力** | 不同材料的热膨胀系数差异 | $\sigma_{th} = \frac{E_f}{1-\nu_f}(\alpha_s - \alpha_f)\Delta T$ |

**典型薄膜残余应力**：

| 薄膜 | 残余应力 (MPa) | 性质 |
|------|---------------|------|
| LPCVD 多晶硅（580°C） | -200 ~ +200 | 可通过退火调控 |
| LPCVD Si₃N₄（800°C） | +800 ~ +1200 | 强张应力 |
| PECVD Si₃N₄（300°C） | -200 ~ +400 | 可调控 |
| 溅射 Al | +50 ~ +200 | 张应力 |
| 蒸发 Au | +10 ~ +100 | 张应力 |

> 注：正值表示张应力（tensile，薄膜趋向收缩），负值表示压应力（compressive，薄膜趋向膨胀）

#### 4.4.2 残余应力对梁结构的影响

- **张应力**：使梁刚度增大（等效杨氏模量增大），谐振频率升高；过大张应力导致梁断裂
- **压应力**：使梁刚度减小，谐振频率降低；当压应力超过**欧拉临界屈曲应力**时梁发生屈曲：

$$\sigma_{cr} = \frac{\pi^2 E}{12}\left(\frac{h}{L}\right)^2 \cdot \frac{1}{1-\nu^2}$$

#### 4.4.3 应力消除与调控

- **退火**：高温退火（>900°C）释放多晶硅残余应力
- **掺硼/磷**：调控多晶硅应力（掺磷减小压应力）
- **沉积参数优化**：温度、压力、功率影响应力
- **多层复合**：交替沉积张/压应力层实现应力平衡
- **退火槽/波纹结构**：设计几何结构释放应力

## 5. MEMS传感器

MEMS 传感器是将物理量（加速度、角速度、压力、声波等）转换为电信号的微型器件。MEMS 传感器的核心优势在于**微型化、低成本、可批量制造和易于与电路集成**。

### 5.1 加速度计（Accelerometer）

#### 5.1.1 工作原理

MEMS 加速度计本质上是**质量块-弹簧-阻尼系统**：

$$m\ddot{x} + c\dot{x} + kx = ma_{ext}$$

其中 $a_{ext}$ 为外部加速度，$x$ 为质量块相对框架的位移。稳态时：

$$x = \frac{m}{k}a_{ext} = \frac{a_{ext}}{\omega_0^2}$$

因此，测量质量块的位移即可得到加速度。

#### 5.1.2 差分电容检测

最常用的位移检测方式是**差分电容**。质量块作为中间极板，两侧固定电极形成电容 $C_1$ 和 $C_2$：

$$C_1 = \frac{\varepsilon_0 A}{d_0 - x}, \quad C_2 = \frac{\varepsilon_0 A}{d_0 + x}$$

差分输出：

$$\Delta C = C_1 - C_2 = \frac{2\varepsilon_0 A x}{d_0^2 - x^2} \approx \frac{2\varepsilon_0 A}{d_0^2}x \quad (x \ll d_0)$$

电容相对变化：

$$\frac{\Delta C}{C_0} \approx \frac{2x}{d_0}$$

其中 $C_0 = \varepsilon_0 A / d_0$ 为静态电容。

#### 5.1.3 加速度计指标

| 指标 | 定义 | 典型值（消费级） | 典型值（工业/导航级） |
|------|------|-----------------|---------------------|
| **量程** | 可测量的加速度范围 | ±2/4/8/16 g | ±0.5~100 g |
| **灵敏度** | 单位加速度的输出变化 | 0.1~1 mg/LSB | 1~10 μg/LSB |
| **带宽** | 可检测信号的频率范围 | 50~500 Hz | 10~5000 Hz |
| **噪声密度** | 单位√Hz的噪声等效加速度 | 100~400 μg/√Hz | 1~50 μg/√Hz |
| **零偏稳定性** | 零输入下输出的漂移 | 0.5~5 mg | 0.01~0.1 mg |
| **温度系数** | 灵敏度/零偏随温度的变化 | ±0.01%/°C | ±0.001%/°C |
| **非线性度** | 实际响应与理想线性的偏差 | ±0.5% FS | ±0.05% FS |

#### 5.1.4 三轴加速度计

单轴加速度计只能测量一个方向的加速度。三轴加速度计通过将三个正交方向的质量块-弹簧系统集成在同一芯片上实现：

- **三芯片堆叠方案**：三个单轴芯片正交组装（精度高，成本高）
- **单芯片方案**：在同一晶圆上设计三个正交方向的质量块，Z 轴利用翘翘板（seesaw）结构（成本低，占主流）
- **6 轴 IMU**：3 轴加速度计 + 3 轴陀螺仪单芯片集成

### 5.2 陀螺仪（Gyroscope）

#### 5.2.1 科里奥利效应原理

MEMS 陀螺仪基于**科里奥利力（Coriolis Force）**检测角速度。当一个质量块以速度 $v$ 在旋转坐标系（角速度 $\Omega$）中运动时，受到科里奥利力：

$$\vec{F}_c = -2m\vec{\Omega} \times \vec{v}$$

大小为：

$$F_c = 2m\Omega v \sin\theta$$

当 $\vec{\Omega} \perp \vec{v}$ 时取最大值 $F_c = 2m\Omega v$。

#### 5.2.2 振动陀螺仪结构

MEMS 陀螺仪几乎全部采用**振动式**结构。质量块沿驱动方向（Drive）持续振动，当芯片绕检测轴旋转时，科里奥利力使质量块在检测方向（Sense）产生振动，通过检测该振幅即可得到角速度。

```
驱动方向 (x): 质量块以 ωd 振动，x(t) = Xd·sin(ωd·t)
    ↕
检测方向 (y): 科里奥利力 Fc = 2m·Ω·ẋ = 2m·Ω·Xd·ωd·cos(ωd·t)
    ↕
检测方向位移: y(t) = Ys·cos(ωd·t) ∝ Ω
```

#### 5.2.3 驱动模态与检测模态

| 参数 | 驱动模态（Drive Mode） | 检测模态（Sense Mode） |
|------|----------------------|----------------------|
| **频率** | $f_d$（通常 10~30 kHz） | $f_s$（接近 $f_d$） |
| **运动** | 持续谐振（自激振荡或锁相驱动） | 科里奥利力驱动 |
| **阻尼** | 低阻尼（高 Q，Qd > 1000） | 可调阻尼 |
| **振幅** | 大（几 μm），提高灵敏度 | 小（nm 级），需高灵敏度检测 |

**模态匹配**：当 $f_s = f_d$ 时，检测模态谐振放大科里奥利力，灵敏度最大（放大 $Q_s$ 倍），但带宽极窄。工程上常使 $f_s$ 略高于 $f_d$（差 50~200 Hz），在灵敏度和带宽间折中。

#### 5.2.4 正交误差与消除

由于加工误差，驱动方向与检测方向不完全正交，导致驱动运动"泄漏"到检测方向，产生**正交误差**（Quadrature Error）。该误差与角速度信号有 90° 相位差，可通过：

1. **解调相位分离**：利用正交误差与科里奥利信号的相位差，通过同步解调分离
2. **力平衡补偿**：施加补偿力消除正交耦合
3. **结构优化**：对称设计、四质量块差分结构

### 5.3 压力传感器（Pressure Sensor）

#### 5.3.1 压阻式压力传感器

在硅膜片上布置压敏电阻，压力使膜片弯曲，电阻值发生变化：

**压阻效应**：

$$\frac{\Delta R}{R} = \pi_l \sigma_l + \pi_t \sigma_t$$

其中 $\pi_l$ 和 $\pi_t$ 分别为纵向和横向压阻系数，$\sigma_l$ 和 $\sigma_t$ 为纵向和横向应力。

**硅的压阻系数**（p 型扩散电阻，$\rho$ = 7.8 Ω·cm）：

| 晶面 | 方向 | $\pi_l$ (10⁻¹¹ Pa⁻¹) | $\pi_t$ (10⁻¹¹ Pa⁻¹) |
|------|------|----------------------|----------------------|
| (100) | <110> | -138.1 | +69.8 |
| (100) | <100> | -8.6 | -8.6 |
| (110) | <110> | -138.1 | +69.8 |
| (111) | 任意 | -55.6 | -55.6 |

**惠斯通电桥**：四个压敏电阻组成全桥，膜片弯曲时两个增大、两个减小：

$$V_{out} = V_s \cdot \frac{\Delta R}{R} = V_s \cdot (\pi_l \sigma_l + \pi_t \sigma_t)$$

灵敏度（压力 $P$ 与输出电压关系）：

$$S = \frac{V_{out}}{P} \approx \frac{V_s}{P}\cdot\frac{\Delta R}{R}$$

典型值：10~100 mV/V/bar

#### 5.3.2 电容式压力传感器

利用压力使膜片弯曲，改变膜片与固定极板间的电容：

$$C = \frac{\varepsilon_0 A}{d_0 - w(P)}$$

其中 $w(P)$ 为膜片中心挠度，与压力的关系（固支圆膜片，小挠度）：

$$w_0 = \frac{P a^4}{64D}, \quad D = \frac{Eh^3}{12(1-\nu^2)}$$

其中 $a$ 为膜片半径，$h$ 为膜片厚度，$D$ 为弯曲刚度。

#### 5.3.3 压阻式与电容式对比

| 特性 | 压阻式 | 电容式 |
|------|--------|--------|
| **灵敏度** | 中 | 高（~10×） |
| **温度系数** | 大（需补偿） | 小 |
| **功耗** | 较高（mA 级） | 低（μA 级） |
| **信号读出** | 简单（电压输出） | 需电容检测电路 |
| **尺寸** | 较大 | 较小 |
| **线性度** | 好 | 较差 |
| **典型应用** | 汽车轮胎气压、工业 | 手机气压计、医疗 |

### 5.4 麦克风（MEMS Microphone）

#### 5.4.1 电容式麦克风原理

MEMS 麦克风的核心是一个**可变电容**：声波使薄膜振动，改变膜与背极板之间的电容：

```
声波 → 薄膜（上极板，可动）→ 间距变化 → 电容变化 → 电信号
              ↕ d₀ + δd
        背极板（下极板，固定，带声学孔）
```

电容变化量：

$$\Delta C \approx C_0 \frac{\delta d}{d_0}$$

**两种工作模式**：

| 模式 | 原理 | 优势 | 典型产品 |
|------|------|------|---------|
| **驻极体（Electret）** | 背极板上永久驻存电荷，无需外部偏压 | 简单、低功耗 | 早期 MEMS 麦克风 |
| **外部偏压** | 施加直流偏压 $V_b$，$\Delta V = V_b \cdot \Delta C / C_0$ | 灵敏度高、一致性好 | 主流方案 |

#### 5.4.2 关键设计参数

| 参数 | 公式/说明 | 典型值 |
|------|----------|--------|
| **灵敏度** | $S = 20\log_{10}(V_{out}/P_{in})$ | -38 ~ -26 dBV/Pa |
| **信噪比（SNR）** | 信号与噪声之比 | 58~70 dB |
| **频率响应** | 可工作的声学频率范围 | 20 Hz ~ 20 kHz |
| **总谐波失真（THD）** | 大信号下的非线性 | < 1% @ 94 dB SPL |
| **膜片厚度** | 越薄灵敏度越高 | 0.5~2 μm |
| **膜片-背极板间距** | 影响电容和灵敏度 | 2~5 μm |

### 5.5 传感器对比表

| 传感器类型 | 检测原理 | 典型灵敏度 | 功耗 | 尺寸 | 主要应用 |
|-----------|---------|-----------|------|------|---------|
| 加速度计（电容式） | 差分电容 | ~1 mg/LSB | 0.1~3 mW | 2×2~3×3 mm² | 手机、汽车、IoT |
| 陀螺仪（振动式） | 科里奥利力+电容检测 | ~0.01°/s/LSB | 1~10 mW | 3×3~4×4 mm² | 手机、IMU、无人机 |
| 压力传感器（压阻式） | 压阻效应 | 10~100 mV/V/bar | 1~5 mW | 2×2~5×5 mm² | 汽车轮胎、工业 |
| 压力传感器（电容式） | 电容变化 | ~1 fF/Pa | 0.01~0.5 mW | 1×1~2×2 mm² | 手机气压计 |
| MEMS 麦克风 | 电容变化 | -38~-26 dBV/Pa | 0.1~0.5 mW | 3×4 mm² | 手机、智能音箱 |

## 6. MEMS执行器

MEMS 执行器将电信号转换为机械运动（位移、力），是实现"微操控"的核心器件。

### 6.1 静电执行器

#### 6.1.1 平行板执行器

最简单的静电执行器由两个平行极板组成，施加电压 $V$ 后产生的静电力：

$$F_e = \frac{1}{2}\frac{\varepsilon_0 A V^2}{d^2}$$

其中 $d$ 为极板间距，$A$ 为极板面积。

**Pull-in 效应**：当极板位移超过初始间距的 1/3 时，静电力增长速度超过弹簧恢复力，极板被迅速吸合到对面——这就是**Pull-in（吸合）不稳定性**。

Pull-in 电压：

$$V_{pi} = \sqrt{\frac{8kd_0^3}{27\varepsilon_0 A}}$$

Pull-in 位移：

$$x_{pi} = \frac{d_0}{3}$$

**可控位移范围**仅为 $0 \sim d_0/3$，严重限制了平行板执行器的行程。

#### 6.1.2 梳状执行器（Comb-Drive）

梳状执行器由交错的梳齿组成，通过侧向静电力驱动：

$$F_l = \frac{N\varepsilon_0 h V^2}{g}$$

其中 $N$ 为梳齿对数，$h$ 为梳齿厚度（结构厚度），$g$ 为梳齿间隙，$V$ 为驱动电压。

**梳状执行器的优势**：

| 特性 | 平行板执行器 | 梳状执行器 |
|------|------------|-----------|
| **力-位移关系** | 非线性（$\propto 1/d^2$） | 近似线性（力与位移无关） |
| **Pull-in** | 有（行程受限） | 无（侧向驱动无 Pull-in） |
| **最大位移** | $\leq d_0/3$ | 可达数十 μm |
| **驱动力** | 中 | 可通过增加梳齿数提高 |
| **驱动电压** | 5~50 V | 10~100 V |
| **典型应用** | RF 开关、微泵 | 微定位、谐振器驱动 |

### 6.2 压电执行器

#### 6.2.1 压电效应

压电材料在受力变形时产生电荷（**正压电效应**），在施加电场时产生变形（**逆压电效应**）：

$$D = d\cdot T + \varepsilon^T \cdot E$$

$$S = s^E \cdot T + d \cdot E$$

其中 $D$ 为电位移，$T$ 为应力，$E$ 为电场，$S$ 为应变，$d$ 为压电系数，$s^E$ 为弹性柔度，$\varepsilon^T$ 为介电常数。

#### 6.2.2 压电材料

| 材料 | $d_{33}$ (pC/N) | $d_{31}$ (pC/N) | 居里温度 $T_c$ (°C) | 特点 |
|------|-----------------|-----------------|---------------------|------|
| **PZT-4** | 289 | -123 | 328 | 硬 PZT，高功率 |
| **PZT-5A** | 374 | -171 | 365 | 软 PZT，通用 |
| **PZT-5H** | 593 | -274 | 193 | 高压电系数 |
| **AlN** | 5.5 | -2.6 | >2000 | CMOS 兼容，低损耗 |
| **ZnO** | 12.4 | -5.0 | — | 可溅射沉积 |
| **PVDF** | 33 | 23 | 100 | 柔性，生物相容 |
| **PMN-PT** | 2000+ | — | 130 | 单晶，极高 $d_{33}$ |

> $d_{33}$：极化方向施加电场，同方向产生应变；$d_{31}$：极化方向施加电场，垂直方向产生应变

#### 6.2.3 压电执行器特性

- **驱动力**：大（$\propto d_{ij} \cdot E$）
- **位移**：中等（单层 ~0.1% 应变，多层堆叠可达 10~100 μm）
- **驱动电压**：PZT 单层需 50~200 V；薄膜（AlN/PZT）可低至 1~10 V
- **响应速度**：快（μs 级）
- **功耗**：低（容性负载，静态几乎零功耗）
- **滞后**：PZT 有明显磁滞回线，AlN 磁滞极小

### 6.3 热执行器

#### 6.3.1 热膨胀驱动

通过焦耳加热使结构膨胀，产生位移：

$$\Delta L = \alpha \cdot L \cdot \Delta T$$

其中 $\alpha$ 为热膨胀系数，$\Delta T$ 为温升。

#### 6.3.2 双金属片效应（冷热臂结构）

MEMS 热执行器常用**冷热臂（Hot-Cold Arm）**结构：

```
        锚点 ─── 热臂（细，高电阻，高 ΔT）───┐
                    ↕ 弯曲                      ├──→ 位移输出
        锚点 ─── 冷臂（粗，低电阻，低 ΔT）───┘
```

热臂膨胀量大，冷臂膨胀量小，二者差产生弯曲。

#### 6.3.3 热执行器特性

| 特性 | 数值/描述 |
|------|----------|
| **位移** | 5~20 μm |
| **驱动力** | 大（mN 级，MEMS 中最大） |
| **驱动电压** | 低（1~10 V） |
| **响应时间** | 慢（0.1~10 ms，受限于热时间常数） |
| **功耗** | 高（mW~数百 mW） |
| **温度限制** | < 600°C（避免结构退化） |

热时间常数：

$$\tau = \frac{\rho c_p V}{G_{th}}$$

其中 $\rho c_p$ 为体积热容，$V$ 为体积，$G_{th}$ 为热导。

### 6.4 电磁执行器

利用洛伦兹力驱动：电流 $I$ 在磁场 $B$ 中受力：

$$F = N \cdot I \cdot L \cdot B$$

MEMS 中需集成永磁体或电磁线圈，工艺复杂，仅在特殊应用中使用（如微镜、微泵）。

### 6.5 执行器对比表

| 执行器类型 | 驱动力 | 位移 | 响应速度 | 驱动电压 | 功耗 | 典型应用 |
|-----------|--------|------|---------|---------|------|---------|
| 静电（平行板） | 中 | 小（≤d₀/3） | 快（μs） | 5~50 V | 极低 | RF 开关、微泵 |
| 静电（梳状） | 小~中 | 大（~100 μm） | 快（μs） | 10~100 V | 极低 | 微定位、谐振器 |
| 压电 | 大 | 中（1~100 μm） | 快（μs） | 1~200 V | 低 | 微泵、微镜、喷墨 |
| 热 | 最大 | 中（5~20 μm） | 慢（ms） | 1~10 V | 高 | 微夹持、光学对准 |
| 电磁 | 中 | 大 | 中（μs~ms） | 低 | 高 | 微镜、微泵 |

## 7. RF MEMS

RF MEMS 是将 MEMS 技术应用于射频前端，用微型机械结构替代传统的固态半导体器件（PIN 二极管、FET 开关等），实现**低损耗、高隔离、高线性度**的射频控制。

### 7.1 RF MEMS开关

#### 7.1.1 电容式开关

电容式开关通过改变极板间距来改变耦合电容，实现信号通断：

**断开状态（UP）**：膜悬空，耦合电容 $C_{off} = \varepsilon_0 A / d_{up}$（极小，~fF 级）

**导通状态（DOWN）**：膜吸合到传输线上，介质层使耦合电容 $C_{on} = \varepsilon_0 \varepsilon_r A / t_d$（极大，~pF 级）

**开关比**：

$$\frac{C_{on}}{C_{off}} = \frac{\varepsilon_r \cdot d_{up}}{t_d}$$

典型值：$C_{on}/C_{off}$ = 50~200

**隔离度（断开态）**：

$$IL_{off} \approx -20\log_{10}(\omega C_{off} Z_0) \text{ (dB)}$$

**插入损耗（导通态）**：

$$IL_{on} \approx 0.05 \sim 0.2 \text{ dB}$$

#### 7.1.2 接触式开关

接触式开关通过金属触点的物理接触/断开来控制信号通路：

- **断开态**：触点分离，信号通路断开
- **导通态**：触点接触，信号直接通过

**特性**：

| 特性 | 电容式 | 接触式 |
|------|--------|--------|
| **工作频段** | 高频（>5 GHz，<5 GHz 隔离度差） | 宽带（DC ~ 40+ GHz） |
| **插入损耗** | 0.05~0.2 dB | 0.1~0.5 dB |
| **隔离度** | 低温频段差 | 全频段好 |
| **功率容量** | 较高（W 级） | 较低（mW~百 mW） |
| **可靠性** | 介电充电问题 | 触点磨损/粘连 |
| **驱动电压** | 10~80 V | 10~80 V |

#### 7.1.3 与固态开关对比

| 指标 | RF MEMS 开关 | PIN 二极管开关 | FET 开关 (SOI) |
|------|-------------|---------------|---------------|
| **插入损耗** | 0.05~0.2 dB | 0.3~0.8 dB | 0.5~1.5 dB |
| **隔离度** | >40 dB | 20~35 dB | 15~30 dB |
| **线性度（IIP3）** | >65 dBm | 30~45 dBm | 30~50 dBm |
| **功耗** | 极低（容性，nW 静态） | 中（mA 级偏流） | 低（μW~mW） |
| **开关速度** | 1~100 μs | 1~100 ns | 1~100 ns |
| **功率容量** | W 级 | W 级 | W 级 |
| **寿命** | 10⁹~10¹² 次 | 近无限 | 近无限 |
| **成本** | 高 | 低 | 中 |

**RF MEMS 开关的瓶颈**：开关速度慢（μs 级 vs ns 级）、驱动电压高、长期可靠性（介电充电、金属蠕变）尚未完全解决。

### 7.2 RF MEMS可变电容

通过静电驱动改变极板间距或交叠面积，实现连续可调的电容值：

$$C(V) = \frac{\varepsilon_0 A}{d_0 - x(V)}$$

**调谐比**：

$$C_{ratio} = \frac{C_{max}}{C_{min}} = \frac{d_0}{d_0 - x_{max}}$$

受 Pull-in 限制，单级调谐比 ≤ 1.5:1。通过**差分结构**或**三极板结构**可突破 Pull-in 限制，实现 3:1 以上的调谐比。

### 7.3 RF MEMS电感

MEMS 技术可实现**高 Q 值**片上电感：

| 改进技术 | 原理 | Q 值提升 |
|---------|------|---------|
| **厚金属（Cu/Au）** | 降低串联电阻 | Q 从 5~10 → 15~25 |
| **悬浮结构** | 去除衬底损耗 | Q → 30~60 |
| **铜屏蔽层** | 隔离衬底涡流 | Q → 20~40 |
| **螺线管/3D 结构** | 减小寄生电容 | Q → 40~80 |

悬浮电感的自谐振频率：

$$f_{SRF} = \frac{1}{2\pi\sqrt{LC_{par}}}$$

## 8. MEMS谐振器

MEMS 谐振器利用硅微机械结构的高 Q 值谐振特性，替代石英晶体实现**频率基准和时钟**功能，是 MEMS 最具商业成功的产品之一（SiTime、Discera/Murata 等）。

### 8.1 机械谐振原理

MEMS 谐振器的等效电路模型为 **LCR 串联谐振电路**：

| 机械参数 | 电学等效 | 关系 |
|---------|---------|------|
| 质量 $m$ | 电感 $L_m$ | $L_m = m / \eta^2$ |
| 刚度 $k$ | 电容 $C_m$ | $C_m = \eta^2 / k$ |
| 阻尼 $c$ | 电阻 $R_m$ | $R_m = c / \eta^2$ |

其中 $\eta$ 为机电转换系数（对电容式：$\eta = V_p \cdot \partial C / \partial x$）。

谐振频率：

$$f_0 = \frac{1}{2\pi\sqrt{L_m C_m}} = \frac{1}{2\pi}\sqrt{\frac{k}{m}}$$

品质因数：

$$Q = \frac{1}{R_m}\sqrt{\frac{L_m}{C_m}} = \frac{\sqrt{km}}{c}$$

MEMS 谐振器在真空中的 Q 值可达 **10,000 ~ 1,000,000**，远高于 LC 谐振器（Q < 50）。

### 8.2 频率稳定性

#### 8.2.1 温度系数（TCF）

硅的杨氏模量随温度升高而降低，导致谐振频率呈负温度系数：

$$TCF = \frac{1}{f_0}\frac{\partial f_0}{\partial T} \approx -30 \text{ ppm/°C}$$

**温度补偿方法**：

| 方法 | 原理 | 补偿后 TCF | 复杂度 |
|------|------|-----------|--------|
| **掺硼补偿** | 掺硼改变弹性常数温度系数 | ±0.1 ppm/°C | 低 |
| **SiO₂ 补偿** | SiO₂ 正 TCF 抵消 Si 负 TCF | ±1 ppm/°C | 中 |
| **电学补偿（PLL）** | 通过 PLL 补偿频率偏移 | ±0.01 ppm/°C | 高 |
| **数字补偿** | 查表法根据温度修正输出频率 | ±0.1 ppm/°C | 高 |

#### 8.2.2 老化

MEMS 谐振器老化主要来源于：

- 薄膜应力释放（前 1~2 年变化最大）
- 污染物沉积在结构上改变质量
- 典型老化：±1~5 ppm/年（首年），之后递减

#### 8.2.3 相位噪声

MEMS 谐振器的相位噪声由 Leeson 模型描述：

$$\mathcal{L}(\Delta f) = 10\log\left[\frac{kT}{P_{sig}}\cdot\frac{f_0^2}{4Q^2\Delta f^2}\right]$$

高 Q 值使近载波相位噪声远低于 LC 振荡器。

### 8.3 与石英晶体对比

| 指标 | 石英晶体 | MEMS 谐振器 |
|------|---------|------------|
| **Q 值** | 10,000~200,000 | 10,000~1,000,000（真空） |
| **频率稳定性** | ±10~50 ppm | ±1~25 ppm（补偿后） |
| **温度稳定性** | ±0.1~50 ppm（AT 切割好） | ±0.1~5 ppm（补偿后） |
| **老化** | ±1~3 ppm/年 | ±1~5 ppm/年 |
| **尺寸** | 2×1.6 mm² ~ 5×3.2 mm² | 0.3×0.3 ~ 2×2 mm² |
| **集成度** | 无法集成（外置） | 可与 CMOS 单封装/单片集成 |
| **成本** | 低（量大） | 中（量产后可更低） |
| **启动时间** | 1~10 ms | 0.1~5 ms |
| **抗振动** | 中 | 好（质量小） |
| **抗冲击** | 中 | 极好（100,000+ g） |
| **可编程性** | 固定频率 | 数字可编程（PLL+分频） |

### 8.4 时钟应用

MEMS 谐振器+CMOS PLL 的组合已成为**可编程时钟发生器**的主流方案：

- **优势**：任意频率输出、快速启动、极小尺寸、抗振动/冲击
- **典型产品**：SiTime SiT9121（0.1~727 MHz 可编程）、Murata XRCGB 系列
- **应用**：网络设备时钟、消费电子时钟、汽车电子、5G 同步时钟

## 9. MEMS封装

MEMS 封装与 IC 封装有本质区别：MEMS 芯片包含**可动的机械结构**，封装必须保护这些结构在制造、运输和使用过程中不受损害，同时允许其与外部环境交互（如压力传感器需与大气连通，麦克风需声学通路）。

### 9.1 MEMS封装的特殊挑战

| 挑战 | 说明 |
|------|------|
| **释放孔/防粘连** | 释放后结构裸露，键合线/塑封料可能进入 |
| **机械保护** | 可动结构在塑封注塑压力下可能变形或断裂 |
| **真空封装** | 高 Q 谐振器/陀螺仪需真空环境 |
| **气密性** | 湿气进入导致腐蚀、粘连、性能退化 |
| **应力隔离** | 封装应力传递到芯片导致零偏/灵敏度漂移 |
| **环境交互** | 压力/气体/声学传感器需与外界连通 |

### 9.2 晶圆级封装（Wafer Level Packaging, WLP）

在晶圆级将 MEMS 结构密封，是最理想的封装方式：

```
MEMS 晶圆（含可动结构）+ 帽晶圆（Cap Wafer）→ 键合 → 切割 → 单颗封装
```

**优势**：

- 在切割前即完成密封，保护可动结构
- 每颗芯片独立密封，可靠性高
- 与标准 IC 封装流程兼容

### 9.3 硅帽封装（Cap Wafer）

最成熟的 MEMS WLP 方案：

1. **MEMS 晶圆**：完成 MEMS 结构加工和释放
2. **帽晶圆**：刻蚀空腔（对应 MEMS 结构位置）
3. **键合**：帽晶圆与 MEMS 晶圆通过玻璃焊料/阳极键合密封

键合方式选择：

| 键合方式 | 气密性 | 真空度 | 成本 | 适用 |
|---------|--------|--------|------|------|
| 玻璃焊料 | 好 | 中（~1 Torr） | 中 | 通用 MEMS |
| 阳极键合 | 极好 | 好（~0.1 Torr） | 中 | 压力传感器 |
| 共晶键合 | 极好 | 好（~0.01 Torr） | 高 | 陀螺仪、谐振器 |
| 金属扩散键合 | 极好 | 极好（<0.001 Torr） | 高 | 高 Q 谐振器 |

### 9.4 真空封装（Vacuum Packaging）

高 Q MEMS 谐振器和陀螺仪需真空封装以降低空气阻尼：

$$Q_{air} = \frac{\rho h \omega}{\mu}\cdot\frac{d}{L}$$

其中 $\mu$ 为空气粘度，$d$ 为间隙，$L$ 为特征长度。

| 封装气压 | Q 值（典型悬臂梁） | 应用 |
|---------|-------------------|------|
| 大气压 (760 Torr) | 10~100 | 加速度计、压力传感器 |
| 1~10 Torr | 100~1000 | 麦克风 |
| 0.01~0.1 Torr | 1000~10000 | 陀螺仪 |
| < 0.001 Torr | > 10000 | 谐振器、滤波器 |

**真空维持**：封装内常放置**吸气剂（Getter）**材料（如 Ti、ZrVFe 合金），持续吸收泄漏和释出的气体，维持长期真空度。

### 9.5 MEMS封装类型

| 封装类型 | 描述 | 典型应用 |
|---------|------|---------|
| **预成型陶瓷封装** | 金属盖密封陶瓷基板，MEMS 芯片粘在基板上 | 高可靠性（汽车、航天） |
| **塑封 QFN/LGA** | 硅帽保护 MEMS 后标准塑封 | 消费级传感器 |
| **晶圆级芯片规模封装（WLCSP）** | 晶圆级密封 + RDL + 焊球 | 超小型传感器 |
| **系统级封装（SiP）** | MEMS + CMOS + 无源器件共封装 | IMU、麦克风 |
| **引线框架封装** | 传统引线键合，MEMS 用硅帽保护 | 低成本压力传感器 |

## 10. MEMS设计流程

MEMS 设计是一个**多物理场、多尺度**的协同设计过程，涉及机械、电学、流体、热学等多学科交叉。

### 10.1 系统级设计（等效电路建模）

将 MEMS 器件用等效电路模型描述，在电路仿真器中进行系统级仿真：

| 机械量 | 电学等效 | 量纲关系 |
|--------|---------|---------|
| 力 $F$ | 电压 $V$ | [N] ↔ [V] |
| 速度 $v$ | 电流 $I$ | [m/s] ↔ [A] |
| 位移 $x$ | 电荷 $Q$ | [m] ↔ [C] |
| 质量 $m$ | 电感 $L$ | [kg] ↔ [H] |
| 刚度 $1/k$ | 电容 $C$ | [m/N] ↔ [F] |
| 阻尼 $c$ | 电阻 $R$ | [N·s/m] ↔ [Ω] |

优势：可在 SPICE/Cadence 中与电路协同仿真，快速迭代。

### 10.2 器件级仿真（有限元分析 FEM）

对 MEMS 结构进行精确的**多物理场耦合仿真**：

| 仿真软件 | 厂商 | 特点 |
|---------|------|------|
| **COMSOL Multiphysics** | COMSOL | 多物理场耦合，易用 |
| **ANSYS Mechanical** | Ansys | 结构力学强 |
| **CoventorWare** | Coventor（Lam Research） | MEMS 专用，工艺仿真集成 |
| **IntelliSuite** | IntelliSense | MEMS 专用，含工艺仿真 |
| **ABAQUS** | Dassault | 非线性力学 |

**典型仿真类型**：

| 仿真类型 | 目的 | 关键输出 |
|---------|------|---------|
| 静力学分析 | 挠度、应力、刚度 | 位移场、应力分布 |
| 模态分析 | 固有频率、模态形状 | 各阶频率、振型 |
| 谐响应分析 | 频域响应 | 幅频/相频特性 |
| 瞬态分析 | 时域动态响应 | 时间-位移曲线 |
| 热力学分析 | 温度分布、热应力 | 温度场、热变形 |
| 流固耦合 | 压膜阻尼 | Q 值、阻尼系数 |

### 10.3 工艺级仿真（Process Simulation）

模拟 MEMS 工艺加工过程，预测实际结构的几何形状和材料特性：

| 工具 | 用途 |
|------|------|
| **Sentaurus Process** | 硅工艺仿真（氧化、扩散、注入、刻蚀） |
| **CoventorWare SEMulator3D** | MEMS 工艺3D建模 |
| **VisualTAPAS** | 各向异性腐蚀仿真 |

工艺仿真可预测：刻蚀轮廓、侧壁形貌、残余应力分布、层间对准误差等。

### 10.4 版图设计

MEMS 版图设计与 IC 版图有显著差异：

| 方面 | IC 版图 | MEMS 版图 |
|------|---------|----------|
| **设计规则** | 统一 DRC | 无标准 DRC，需工艺定制 |
| **关键尺寸** | 晶体管尺寸 | 梁宽/厚/间距、梳齿参数 |
| **对称性** | 电流匹配 | 力学对称（热/应力对称） |
| **锚点设计** | 无 | 关键——影响刚度和应力 |
| **释放孔** | 无 | 需设计释放孔（加速腐蚀液进入） |
| **刻蚀补偿** | 无 | 凸角补偿（各向异性腐蚀） |

### 10.5 掩模制造与流片

完整的 MEMS 制造流程：

```
设计完成 → 版图输出 (GDSII) → 掩模制造 → 晶圆加工 → 划片 → 封装 → 测试
```

**MEMS 流片方式**：

| 方式 | 说明 | 成本 | 周期 |
|------|------|------|------|
| **MPW（多项目晶圆）** | 多个设计共享一片晶圆 | 低（~$5,000~50,000） | 长（3~6 月） |
| **全定制流片** | 专用掩模和工艺 | 高（~$100,000~500,000+） | 长 |
| **研究型代工** | 大学/研究机构提供标准 MEMS 工艺 | 极低 | 较短 |

**典型 MEMS MPW 服务**：

| 代工服务 | 工艺 | 特点 |
|---------|------|------|
| **SUMMiT（Sandia）** | 5 层多晶硅表面微加工 | 高复杂度结构 |
| **MUMPs（MEMSCAP）** | PolyMUMPs/MetalMUMPs/SoiMUMPs | 经典教学/研究工艺 |
| **PiezoMUMPs（MEMSCAP）** | AlN 压电 + SOI | 压电 MEMS |
| **iMEMS（台积电）** | CMOS + MEMS 集成 | 商业级 |

## 11. 小结

MEMS 技术是微电子领域中**"超越摩尔"路线的典范**，将微型化机械结构与电子电路集成，实现了对物理世界的感知与操控。本章系统介绍了 MEMS 的核心内容：

1. **工艺技术**：体硅微加工（各向异性腐蚀、DRIE）适合制造深腔和高质量块结构；表面微加工（牺牲层技术）适合制造悬空梁和梳状结构；LIGA 工艺适合高深宽比金属结构；键合技术是实现 MEMS 封装和真空腔体的关键。

2. **力学基础**：胡克定律 $\sigma = E\varepsilon$ 是 MEMS 弹性设计的基石；梁的弯曲理论（欧拉-伯努利方程）为悬臂梁、固支梁的刚度和挠度计算提供依据；谐振频率 $f_0 = (1/2\pi)\sqrt{k/m}$ 及其与结构参数的关系是动态设计的基础；残余应力对 MEMS 结构的刚度和稳定性有显著影响。

3. **传感器**：加速度计通过质量块-弹簧系统和差分电容检测实现；陀螺仪基于科里奥利效应，驱动模态和检测模态的设计是关键；压力传感器分为压阻式和电容式，各有优劣；MEMS 麦克风凭借小尺寸和高性能已全面取代传统驻极体麦克风。

4. **执行器**：静电执行器（平行板有 Pull-in 限制，梳状无 Pull-in）功耗极低但需高压驱动；压电执行器驱动力大、响应快；热执行器驱动力最大但响应慢、功耗高。执行器的选择需综合考虑力/位移/速度/功耗的需求。

5. **RF MEMS**：MEMS 开关在插入损耗、隔离度和线性度上远优于固态开关，但开关速度和可靠性仍是瓶颈；MEMS 可变电容、高 Q 电感和谐振器为可重构射频前端提供了新途径。

6. **谐振器**：MEMS 谐振器利用硅的高 Q 机械谐振特性替代石英晶体，通过温度补偿（掺杂、SiO₂、PLL）实现高稳定性，其可编程性、小尺寸和抗冲击特性使其在时钟应用中快速普及。

7. **封装**：MEMS 封装需保护可动结构、维持真空、实现气密性并提供环境交互通道；晶圆级封装（硅帽键合）是主流方案；吸气剂技术维持长期真空。

8. **设计流程**：从系统级等效电路建模，到器件级有限元仿真（FEM），再到工艺级仿真和版图设计，MEMS 设计是多物理场、多尺度的协同优化过程。

MEMS 技术的本质是**机械学与电子学的微型化融合**。随着 5G/6G 射频前端、自动驾驶惯性导航、AR/VR 微显示、BioMEMS 即时诊断等应用的蓬勃发展，MEMS 将继续是微电子领域最具活力和增长潜力的方向之一。
